# @stefan-florescu/icons

Thin, governed layer over [lucide.dev](https://lucide.dev) (`lucide-react`).

- Components import icons **only** from `@stefan-florescu/icons` (enforced by lint later).
- Defaults (size scale, stroke width, colour = `currentColor`, `aria-hidden` unless labelled)
  will be specified in the Icon foundation (Phase A).

> Status: **scaffold only**.
