## Spacing scale

Base unit **4px**: `0, 2, 4, 6, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96`.

## Semantic spacing

`inset` (padding), `stack` (vertical gap), `inline` (horizontal gap) and `section` (layout).

## Grid

A 12-column fluid grid: 4 columns on mobile, 8 on tablet, 12 from `lg`.

## Breakpoints

| Token | Width  |
| ----- | ------ |
| `sm`  | 640px  |
| `md`  | 768px  |
| `lg`  | 1024px |
| `xl`  | 1280px |
| `2xl` | 1536px |
