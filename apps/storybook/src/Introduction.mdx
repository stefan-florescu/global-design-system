# Stefan Design System — Workbench

This Storybook is the **component workbench**: isolated development, visual states,
interaction tests and automated accessibility checks for every component in
`packages/ui`.

- Long-form guidance (when to use, content, patterns) lives in the **docs site** (`apps/docs`).
- Toggle **light / dark** from the toolbar — themes are applied with `data-theme`.
- The **Accessibility** panel runs axe-core on every story; violations are errors.
