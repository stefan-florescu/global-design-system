## Accessibility

- The field is a native spin button: <kbd>↑</kbd> and <kbd>↓</kbd> change the value by `step`.
- The − and + buttons are named "Decrease" and "Increase" (change them with `decrementLabel` and
  `incrementLabel`) and point at the field with `aria-controls`.
- Use `NumberInput` for amounts. For codes and IDs (ZIP codes, card numbers), use `Input` with
  `inputMode="numeric"`: they aren't numbers you count up or down.

## API Reference

| Prop             | Type                              | Default      |
| ---------------- | --------------------------------- | ------------ |
| `value`          | `number \| null`                  | —            |
| `defaultValue`   | `number \| null`                  | `null`       |
| `onValueChange`  | `(value: number \| null) => void` | —            |
| `min` / `max`    | `number`                          | —            |
| `step`           | `number`                          | `1`          |
| `stepper`        | `boolean`                         | `false`      |
| `decrementLabel` | `string`                          | `"Decrease"` |
| `incrementLabel` | `string`                          | `"Increase"` |
| `size`           | `"sm" \| "md" \| "lg"`            | `"md"`       |
| `invalid`        | `boolean`                         | `false`      |
| `valid`          | `boolean`                         | `false`      |

`NumberInput` is a client component.
