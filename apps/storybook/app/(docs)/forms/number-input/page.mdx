```tsx

```

```tsx

<NumberInput id="quantity" stepper defaultValue={2} min={1} max={10} />
```

## Accessibility

- The field is a native `type="number"` input, exposed as a spin button: <Kbd>↑</Kbd> and
  <Kbd>↓</Kbd> change the value by `step`.
- The − and + buttons are named by `decrementLabel` and `incrementLabel` ("Decrease", "Increase"),
  point at the field with `aria-controls`, and are disabled at `min` and `max`.
- Differences from Flowbite, for WCAG 2.2 AA:
  - Flowbite removes the counter field's focus ring; ours keeps the solid `ring` outline for
    keyboard focus. Every button also draws it around Flowbite's soft halo.
  - Flowbite's control-button field falls back to black 16px text; ours uses the `heading` colour
    and the field's 14px text, so it stays readable in dark mode.
- Counter buttons are 24×24px, the WCAG 2.5.8 minimum target size.

## API Reference

### NumberInput

Takes every `Input` prop except `type`, `value`, `defaultValue`, `onChange`, `min`, `max` and `step`.

| Prop             | Type                              | Default      |
| ---------------- | --------------------------------- | ------------ |
| `value`          | `number \| null`                  | —            |
| `defaultValue`   | `number \| null`                  | `null`       |
| `onValueChange`  | `(value: number \| null) => void` | —            |
| `min`            | `number`                          | —            |
| `max`            | `number`                          | —            |
| `step`           | `number`                          | `1`          |
| `stepper`        | `boolean`                         | `false`      |
| `variant`        | `"default" \| "counter"`          | `"default"`  |
| `caption`        | `ReactNode`                       | —            |
| `size`           | `"sm" \| "md" \| "lg" \| "xl"`    | `"md"`       |
| `decrementLabel` | `string`                          | `"Decrease"` |
| `incrementLabel` | `string`                          | `"Increase"` |
