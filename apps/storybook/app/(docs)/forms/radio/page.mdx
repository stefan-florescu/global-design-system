## Usage

```tsx
import { Fieldset, Radio } from "@stefan-florescu/ui";
```

```tsx
<Fieldset legend="Plan">
  <Radio name="plan" value="free" label="Free" defaultChecked />
  <Radio name="plan" value="pro" label="Pro" />
</Fieldset>
```

## Accessibility

- Native radios: <kbd>Tab</kbd> moves into the group, arrow keys move the selection, as in the
  WAI-ARIA radio group pattern.
- The `Fieldset` legend names the group; every radio has its own label.
- Pre-select a sensible default where one exists, so the group always has a value.

## API Reference

### Radio

| Prop          | Type        | Default |
| ------------- | ----------- | ------- |
| `label`       | `ReactNode` | —       |
| `description` | `ReactNode` | —       |
| `bordered`    | `boolean`   | `false` |
| `invalid`     | `boolean`   | `false` |

All other `<input>` attributes are forwarded, such as `name`, `value` and `defaultChecked`.

### Fieldset

| Prop          | Type                         | Default      |
| ------------- | ---------------------------- | ------------ |
| `legend`      | `ReactNode` (required)       | —            |
| `hideLegend`  | `boolean`                    | `false`      |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` |

`className` styles the `<fieldset>`; `contentClassName` styles the element that lays out the
controls, for example a grid.
