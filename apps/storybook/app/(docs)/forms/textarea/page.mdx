## Usage

```tsx
import { Label, Textarea } from "@stefan-florescu/ui";
```

```tsx
<Label htmlFor="message">Your message</Label>
<Textarea id="message" rows={4} placeholder="Write your thoughts here..." />
```

## Accessibility

- Every textarea needs a `Label` whose `htmlFor` matches its `id`; in compact layouts such as the
  editor, comment box and chat input, make it `sr-only`. Placeholders are hints, not labels.
- Link helper and error text with `aria-describedby` so it is read with the field. `invalid` sets
  `aria-invalid="true"`; always say what is wrong in text too.
- Differences from Flowbite, for WCAG 2.2 AA: the field border is the `input` token instead of
  `default-medium`, so its edge reaches 3:1 against the page (1.4.11). In the editor and comment
  box the inner textarea has no border, so the outer box shows the `brand` focus border and ring
  (Flowbite shows no focus there).
- Icon-only toolbar buttons are `Button`s with an `aria-label`, so they keep the keyboard focus
  outline. Flowbite's "Show full screen" tooltip is a native `title` here.

## API Reference

| Prop        | Type                          | Default |
| ----------- | ----------------------------- | ------- |
| `rows`      | `number`                      | `4`     |
| `invalid`   | `boolean`                     | `false` |
| `valid`     | `boolean`                     | `false` |
| `disabled`  | `boolean`                     | `false` |
| `className` | `string`. Merged with `cn()`. | —       |

All other `<textarea>` attributes are forwarded, including `ref`.

| Part  | Tokens                                                                                      |
| ----- | ------------------------------------------------------------------------------------------- |
| Field | `neutral-secondary-medium` · `input` border · `heading` text · `rounded-base` · `shadow-xs` |
| Focus | `brand` border and ring                                                                     |
