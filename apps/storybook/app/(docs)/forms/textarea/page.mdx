## Accessibility

- Every field needs a visible `Label` whose `htmlFor` matches the field's `id`. Placeholders are
  hints, not labels.
- Link helper and error text with `aria-describedby` so it is read with the field.
- `invalid` sets `aria-invalid="true"` and a red border; always say what is wrong in text too.
- The border uses the `input` token, which clears 3:1 against the page in both themes, and focus
  adds a `ring`-coloured border and ring.
- Name icon-only buttons next to the field, such as "Send message".

## API Reference

| Prop      | Type                   | Default |
| --------- | ---------------------- | ------- |
| `rows`    | `number`               | `4`     |
| `size`    | `"sm" \| "md" \| "lg"` | `"md"`  |
| `invalid` | `boolean`              | `false` |
| `valid`   | `boolean`              | `false` |
