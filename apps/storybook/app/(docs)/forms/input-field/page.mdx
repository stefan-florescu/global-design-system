## Usage

```tsx
import { HelperText, Input, Label } from "@stefan-florescu/ui";
```

```tsx
<div className="grid gap-2">
  <Label htmlFor="email">Email address</Label>
  <Input id="email" type="email" aria-describedby="email-help" />
  <HelperText id="email-help">We'll never share your email.</HelperText>
</div>
```

## Accessibility

- Every field needs a visible `Label` whose `htmlFor` matches the field's `id`. Placeholders are
  hints, not labels.
- Link helper and error text with `aria-describedby` so it is read with the field.
- `invalid` sets `aria-invalid="true"` and a red border; always say what is wrong in text too.
- The border uses the `input` token, which clears 3:1 against the page in both themes, and focus
  adds a `ring`-coloured border and ring.

## API Reference

### Input

| Prop        | Type                   | Default  |
| ----------- | ---------------------- | -------- |
| `size`      | `"sm" \| "md" \| "lg"` | `"md"`   |
| `invalid`   | `boolean`              | `false`  |
| `valid`     | `boolean`              | `false`  |
| `startIcon` | `ReactNode`            | —        |
| `endIcon`   | `ReactNode`            | —        |
| `addon`     | `ReactNode`            | —        |
| `type`      | `string`               | `"text"` |

### Label

| Prop       | Type      | Default |
| ---------- | --------- | ------- |
| `required` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |

### HelperText

| Prop      | Type                                | Default     |
| --------- | ----------------------------------- | ----------- |
| `variant` | `"default" \| "error" \| "success"` | `"default"` |

All parts forward native attributes, including `ref` and `className`.
