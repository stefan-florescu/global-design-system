## Accessibility

- A native checkbox with `role="switch"`: screen readers announce "switch, on/off", <kbd>Space</kbd>
  toggles it, and it submits with forms like a checkbox.
- The off track uses the `input` colour and the on track `brand`, both 3:1 against the page; the
  knob position shows the state without relying on colour.
- Use a toggle for settings that apply at once. For choices confirmed by a submit button, use a
  checkbox.

## API Reference

| Prop          | Type                   | Default |
| ------------- | ---------------------- | ------- |
| `label`       | `ReactNode`            | —       |
| `description` | `ReactNode`            | —       |
| `size`        | `"sm" \| "md" \| "lg"` | `"md"`  |

All other `<input>` attributes are forwarded, such as `name`, `checked` and `defaultChecked`.
