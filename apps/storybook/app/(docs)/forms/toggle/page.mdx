## Accessibility

- A native checkbox with `role="switch"`: screen readers announce "switch, on/off", <kbd>Space</kbd>
  toggles it, and it submits with forms like a checkbox.
- The off track is Flowbite's gray-200 (`input`) and the on track is `brand`; the knob position
  shows the state without relying on colour.
- Focus shows Flowbite's soft `brand-soft` halo; keyboard focus also draws a solid 2px `ring`
  outline, because the halo alone is under 3:1.
- The knob stops animating when the user prefers reduced motion.
- With a `description`, the title names the switch and the description is read as its description.
- Use a toggle for settings that apply at once. For choices confirmed by a submit button, use a
  checkbox.
- Not ported: Flowbite's _Colors_ example (uses palette colours we have no tokens for). The card
  with icon shows a generic icon instead of Flowbite's brand logo.

## API Reference

| Prop          | Type                                  | Default |
| ------------- | ------------------------------------- | ------- |
| `label`       | `ReactNode`                           | —       |
| `description` | `ReactNode`                           | —       |
| `size`        | `"md" \| "lg"`                        | `"md"`  |
| `bordered`    | `boolean`                             | `false` |
| `icon`        | `ReactNode` (shown before the switch) | —       |

All other `<input>` attributes are forwarded, such as `name`, `checked`, `defaultChecked` and
`disabled`. `className` styles the outer `<label>`.
