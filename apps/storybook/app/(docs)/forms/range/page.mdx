## Usage

```tsx
import { Label, Range } from "@stefan-florescu/ui";
```

```tsx
<Label htmlFor="volume">Volume</Label>
<Range id="volume" min={0} max={100} defaultValue={50} />
```

## Accessibility

- A native slider: arrow keys change the value by `step`, <Kbd>Page Up</Kbd>/<Kbd>Page Down</Kbd>
  by larger amounts, <Kbd>Home</Kbd>/<Kbd>End</Kbd> jump to the limits.
- Give it a `Label`, and `aria-valuetext` when the number alone isn't meaningful (for example
  "70%").
- The thumb is `brand`, 3:1 against the page. Focus shows Flowbite's `brand-medium` halo around it;
  keyboard focus also draws a solid 2px `ring` outline around the slider.
- In forced-colors (high contrast) mode the browser draws the slider itself, so it stays visible.
- Show the exact value when it matters; sliders are hard to set precisely.

## API Reference

| Prop          | Type                   | Default     |
| ------------- | ---------------------- | ----------- |
| `min` / `max` | `number`               | `0` / `100` |
| `step`        | `number`               | `1`         |
| `size`        | `"sm" \| "md" \| "lg"` | `"md"`      |

All other `<input>` attributes are forwarded, such as `value`, `defaultValue`, `onChange` and
`disabled`.
