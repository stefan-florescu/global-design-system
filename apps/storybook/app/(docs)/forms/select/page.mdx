## Usage

```tsx
import { Label, Select } from "@stefan-florescu/ui";
```

```tsx
<Label htmlFor="country">Country</Label>
<Select id="country" defaultValue="">
  <option value="">Choose a country</option>
  <option value="ro">Romania</option>
</Select>
```

## Accessibility

- A native `<select>`, so keyboard, screen-reader and mobile pickers work as people expect.
- Give it a `Label`. The chevron is decorative.
- Multiple selection is hard to discover; for a few options, prefer checkboxes.

## API Reference

| Prop       | Type                       | Default     |
| ---------- | -------------------------- | ----------- |
| `variant`  | `"default" \| "underline"` | `"default"` |
| `htmlSize` | `number`                   | —           |
| `size`     | `"sm" \| "md" \| "lg"`     | `"md"`      |
| `invalid`  | `boolean`                  | `false`     |
| `valid`    | `boolean`                  | `false`     |

All other `<select>` attributes are forwarded.
