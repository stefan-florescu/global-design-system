## Usage

```tsx
import { Label, SearchInput } from "@stefan-florescu/ui";
```

```tsx
<form role="search">
  <Label htmlFor="q" className="sr-only">
    Search
  </Label>
  <SearchInput id="q" submitLabel="Search" />
</form>
```

## Accessibility

- Renders `type="search"`, announced as a search box. Wrap it in `<form role="search">` so it is
  listed as a search landmark.
- Give it a `Label`; a visually hidden one (`className="sr-only"`) is fine when the icon and
  button make the purpose obvious.
- The search icon is decorative and hidden from assistive technology.

## API Reference

| Prop          | Type                   | Default |
| ------------- | ---------------------- | ------- |
| `submitLabel` | `string`               | —       |
| `size`        | `"sm" \| "md" \| "lg"` | `"md"`  |
| `invalid`     | `boolean`              | `false` |
| `valid`       | `boolean`              | `false` |

Also accepts every `Input` prop except `type` and `startIcon`.
