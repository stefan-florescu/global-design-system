## Usage

```tsx
import { Label, SearchInput } from "@stefan-florescu/ui";
```

```tsx
<form role="search">
  <Label htmlFor="q" className="sr-only">
    Search
  </Label>
  <SearchInput id="q" placeholder="Search" submitLabel="Search" />
</form>
```

## Accessibility

- Put the field in a `<form role="search">` so it is announced as a search landmark.
- Every field and select needs a label; these layouts use `sr-only` labels, as Flowbite does.
- The search icon is decorative and hidden from assistive technology. The voice search and icon-only
  submit buttons have an `aria-label`.
- Keyboard focus draws the solid `ring` outline on buttons and selects, around Flowbite's soft halo.
- The field border uses the `input` token instead of Flowbite's `default-medium` so it reaches 3:1
  against the page.

## API Reference

### SearchInput

Takes every `Input` prop except `type` and `startIcon`.

| Prop          | Type                           | Default      |
| ------------- | ------------------------------ | ------------ |
| `size`        | `"sm" \| "md" \| "lg" \| "xl"` | `"md"`       |
| `icon`        | `ReactNode`                    | `<Search />` |
| `submitLabel` | `string`                       | —            |
| `invalid`     | `boolean`                      | `false`      |
| `valid`       | `boolean`                      | `false`      |

### Tokens

| Part          | Tokens                                                                                         |
| ------------- | ---------------------------------------------------------------------------------------------- |
| Field         | `neutral-secondary-medium` · `input` border · `heading` · `body` · `shadow-xs` · `radius-base` |
| Icon          | `body`                                                                                         |
| Submit button | `brand` · `brand-strong` on hover · `brand-foreground` · `radius` (8px)                        |
| Select        | `neutral-secondary-medium` · `neutral-tertiary-medium` on hover · `body`                       |
