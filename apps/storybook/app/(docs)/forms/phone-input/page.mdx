## Accessibility

- Give the number field a `Label`; the country select is named by `countryLabel` ("Country code").
- `autoComplete="tel-national"` and `inputMode="tel"` let browsers fill the number and show a phone
  keypad on mobile.
- `invalid` marks both the select and the field with `aria-invalid`; explain the problem in text.
- For WCAG 2.2 AA, keyboard focus on the select draws the solid `ring` outline around its soft halo.

## API Reference

### PhoneInput

Takes every `Input` prop except `type`, `addon` and `startIcon`; `className`, `id` and `ref` go to
the number field.

| Prop             | Type                           | Default                 |
| ---------------- | ------------------------------ | ----------------------- |
| `countries`      | `PhoneCountry[]`               | `defaultPhoneCountries` |
| `defaultCountry` | `string`                       | first country's `code`  |
| `countryName`    | `string`                       | —                       |
| `countryLabel`   | `string`                       | `"Country code"`        |
| `endAddon`       | `ReactNode`                    | —                       |
| `size`           | `"sm" \| "md" \| "lg" \| "xl"` | `"md"`                  |
| `invalid`        | `boolean`                      | `false`                 |
| `valid`          | `boolean`                      | `false`                 |

`PhoneCountry` is `{ code: string; dialCode: string; name: string }`.
