## Accessibility

- The number field is `type="tel"` with `autoComplete="tel-national"`, so phones show a dial
  pad and browsers can fill it in.
- The country select has its own name, "Country code" (change it with `countryLabel`), and each
  option is read with the full country name.
- Submit both values: `name` for the number and `countryName` for the country.

## API Reference

| Prop             | Type                   | Default                 |
| ---------------- | ---------------------- | ----------------------- |
| `countries`      | `PhoneCountry[]`       | `defaultPhoneCountries` |
| `defaultCountry` | `string`               | First country           |
| `countryName`    | `string`               | —                       |
| `countryLabel`   | `string`               | `"Country code"`        |
| `size`           | `"sm" \| "md" \| "lg"` | `"md"`                  |
| `invalid`        | `boolean`              | `false`                 |
| `valid`          | `boolean`              | `false`                 |

`PhoneCountry` is `{ code, dialCode, name }`. Other props go to the number field.
