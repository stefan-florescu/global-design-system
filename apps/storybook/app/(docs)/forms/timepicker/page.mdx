## Usage

```tsx
import { Label, Timepicker } from "@stefan-florescu/ui";
```

```tsx
<Label htmlFor="time">Select time:</Label>
<Timepicker id="time" min="09:00" max="18:00" defaultValue="00:00" required />
```

## Accessibility

- A native `type="time"` field, so each part (hours, minutes, AM/PM) is reachable with the keyboard
  and read correctly by screen readers. The clock icon is decorative (`aria-hidden`).
- The submitted value is always 24-hour `HH:mm`, whatever the display format. `min`, `max` and
  `step` (seconds) limit the choices; explain limits such as office hours in a `HelperText`.
- Differences from Flowbite, for WCAG 2.2 AA: field borders are the `input` token instead of
  `default-medium`, so their edges reach 3:1 (1.4.11). Flowbite's time slots hide their radio
  inputs with `display: none`, which removes them from the keyboard and screen readers; here they
  are visually hidden (`sr-only`), keep the arrow-key radio behaviour and draw the `ring` outline
  around the slot on keyboard focus. Slot labels on the `brand` fill use `brand-foreground`.

## API Reference

| Prop          | Type                                           | Default     |
| ------------- | ---------------------------------------------- | ----------- |
| `icon`        | `ReactNode`. `null` renders the bare field.    | `<Clock />` |
| `min` / `max` | `string` (`"HH:mm"`)                           | —           |
| `step`        | `number` (seconds)                             | `60`        |
| `invalid`     | `boolean`                                      | `false`     |
| `valid`       | `boolean`                                      | `false`     |
| `className`   | `string`. Merged with `cn()` on the `<input>`. | —           |

All other `<input>` attributes are forwarded to the field, including `ref`.

| Part  | Tokens                                                                                      |
| ----- | ------------------------------------------------------------------------------------------- |
| Field | `neutral-secondary-medium` · `input` border · `heading` text · `rounded-base` · `shadow-xs` |
| Icon  | `body`                                                                                      |
| Focus | `brand` border and ring                                                                     |
