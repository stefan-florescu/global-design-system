## Usage

```tsx
import { Label, Timepicker } from "@stefan-florescu/ui";
```

```tsx
<Label htmlFor="start">Start time</Label>
<Timepicker id="start" min="09:00" max="18:00" step={1800} />
```

## Accessibility

- A native `type="time"` field, so each part (hours, minutes) is reachable with the keyboard and
  read correctly by screen readers.
- The submitted value is always 24-hour `HH:mm`, whatever the display format.
- Explain limits such as office hours in a `HelperText`.

## API Reference

| Prop          | Type                   | Default |
| ------------- | ---------------------- | ------- |
| `min` / `max` | `string` (`"HH:mm"`)   | —       |
| `step`        | `number` (seconds)     | `60`    |
| `size`        | `"sm" \| "md" \| "lg"` | `"md"`  |
| `invalid`     | `boolean`              | `false` |
| `valid`       | `boolean`              | `false` |
