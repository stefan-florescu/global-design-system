## Usage

```tsx
import { Label, Timepicker } from "@stefan-florescu/ui";
```

```tsx
<Label htmlFor="time">Select time:</Label>
<Timepicker id="time" min="09:00" max="18:00" defaultValue="00:00" required />
```

## Examples

### Default timepicker

A native `type="time"` field with a clock icon. The browser formats the time for the user's locale
and supplies the picker; clicking the icon opens it.

Pass `icon={null}` for the bare field and attach the icon as an addon at its end.

<ComponentPreview name="timepicker-icon" />

### Timepicker with dropdown

Join a `Dropdown` to the end of the field for options such as the duration of an event. The chosen
option replaces the button's label.

<ComponentPreview name="timepicker-dropdown" />

### Timepicker with select

Attach a `Select` to the end of the field to choose an option such as the timezone.

<ComponentPreview name="timepicker-select" />

### Timepicker range selector

Use two timepickers to choose a time interval, such as the duration of an event.

<ComponentPreview name="timepicker-range" />

### Timerange with dropdown

Show the time range inside a `Dropdown` only when the button is clicked. "Save time" is a
`DropdownItem`, so choosing it closes the dropdown and returns focus to the button.

<ComponentPreview name="timepicker-range-dropdown" />

### Timerange picker with toggle

Show or hide the time range with a disclosure button. The button sets `aria-expanded` and
`aria-controls`.

<ComponentPreview name="timepicker-toggle" />

### Inline timepicker buttons

Show the details of an event, choose the day in an inline `Calendar`, and choose the time from a
set of slots. The slots are radio buttons styled as buttons, so arrow keys move between them.

<ComponentPreview name="timepicker-inline" />

### Modal with timepicker

Choose the day in an inline `Calendar` and the time from a set of slots inside a `Modal`, to
schedule an appointment. "Save" submits the form and closes the modal; "Discard" closes it.

<ComponentPreview name="timepicker-modal" />

### Drawer with timepicker

Schedule several time intervals, such as one per working day, inside a `Drawer`. Delete a day's
interval with its trash button, or add one back with "Add interval".

## Accessibility

- A native `type="time"` field, so each part (hours, minutes, AM/PM) is reachable with the keyboard
  and read correctly by screen readers. The clock icon is decorative (`aria-hidden`).
- The submitted value is always 24-hour `HH:mm`, whatever the display format. `min`, `max` and
  `step` (seconds) limit the choices; explain limits such as office hours in a `HelperText`.
- Differences from Flowbite, for WCAG 2.2 AA: Flowbite's time slots hide their radio
  inputs with `display: none`, which removes them from the keyboard and screen readers; here they
  are visually hidden (`sr-only`), keep the arrow-key radio behaviour and draw the `ring` outline
  around the slot on keyboard focus. Slot labels on the `brand` fill use `brand-foreground`.
- The duration dropdown is a WAI-ARIA menu button; once a duration is chosen, the button reads
  "Duration: 1 hour". The time range dropdown is a non-modal dialog named "Time range": focus moves
  to the start time when it opens, and <Kbd>Escape</Kbd> or "Save time" closes it and returns focus
  to the button.
- The schedule drawer is a modal dialog named by its title: focus stays inside it until it closes.
  Each day's checkbox and time fields are named with the full day ("Monday start time"), and the
  trash buttons say which interval they delete. Deleting a row moves focus to "Add interval", and
  adding one moves focus to the new row. Flowbite pins "Close" and "Save all" over the bottom of the
  drawer; here they sit at the bottom but in the flow, so they never cover a field on short
  screens.
- The appointment modal is a modal dialog named by its title. Its time slots are the same
  radio buttons as the inline example, grouped under "Pick your time".

## API Reference

| Prop          | Type                                           | Default     |
| ------------- | ---------------------------------------------- | ----------- |
| `icon`        | `ReactNode`. `null` renders the bare field.    | `<Clock />` |
| `min` / `max` | `string` (`"HH:mm"`)                           | —           |
| `step`        | `number` (seconds)                             | `60`        |
| `invalid`     | `boolean`                                      | `false`     |
| `valid`       | `boolean`                                      | `false`     |
| `className`   | `string`. Merged with `cn()` on the `<input>`. | —           |

All other `<input>` attributes are forwarded to the field, including `ref`.

| Part  | Tokens                                                                                      |
| ----- | ------------------------------------------------------------------------------------------- |
| Field | `neutral-secondary-medium` · `input` border · `heading` text · `rounded-base` · `shadow-xs` |
| Icon  | `body`                                                                                      |
| Focus | `brand` border and ring                                                                     |
