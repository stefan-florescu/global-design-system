A native file field to upload a single file. The browser's "Choose file" button is a segment inside
the start of the field, 4px from its border, with its start corners rounded to 8px: the field's 12px

### Sizes

`md` (Flowbite's base) and `lg`; `sm` is also available. Fields are 38, 42 and 50px tall, like the
other fields; the size sets the file name's text and the button's padding.

### Dropzone

`FileDropzone` is a large area that people can click, focus with <Kbd>Tab</Kbd>, or drop files on.
It works without JavaScript: the native file input covers the whole area.

### Dropzone with button

Use a `Button` to open the file dialog instead of making the whole area clickable.

## Accessibility

- Both are native `type="file"` inputs, so the file dialog, keyboard and screen readers work as
  usual. Give `FileInput` a `Label`; `FileDropzone`'s own text is its label.
- `accept` only filters the file dialog; check files on the server too.
- Differences from Flowbite, for WCAG 2.2 AA:
  - In dark mode the "Choose file" label is `heading` instead of `body`, because `body` on
    `neutral-quaternary` is under 4.5:1 there (1.4.3).
  - Flowbite hides the dropzone's input with `display: none`, so it cannot be reached with the
    keyboard. Here the input is invisible but covers the area, and keyboard focus outlines the
    whole dropzone in `ring`.
- In the dropzone with button, the `Button` opens the dialog, so the hidden input stays out of the
  tab order.

## API Reference

### FileInput

| Prop        | Type                          | Default |
| ----------- | ----------------------------- | ------- |
| `size`      | `"sm" \| "md" \| "lg"`        | `"md"`  |
| `accept`    | `string`                      | —       |
| `multiple`  | `boolean`                     | `false` |
| `invalid`   | `boolean`                     | `false` |
| `disabled`  | `boolean`                     | `false` |
| `className` | `string`. Merged with `cn()`. | —       |

### FileDropzone

| Prop          | Type        | Default                            |
| ------------- | ----------- | ---------------------------------- |
| `title`       | `ReactNode` | "Click to upload or drag and drop" |
| `description` | `ReactNode` | —                                  |
| `className`   | `string`    | —                                  |

Both forward the other native `<input>` attributes to the file input, including `ref`;
`FileDropzone`'s `className` goes on the drop area.

| Part          | Tokens                                                                                                |
| ------------- | ----------------------------------------------------------------------------------------------------- |
| Field         | `neutral-secondary-medium` · `input` border · `heading` · `rounded-base`                              |
| Choose button | `neutral-quaternary` · `body` (`heading` in dark)                                                     |
| Dropzone      | `neutral-secondary-medium` · dashed `input` border · `body` text · `neutral-tertiary-medium` on hover |
