### Dropzone

`FileDropzone` is a large target: click it, focus it with <kbd>Tab</kbd>, or drop files on it. It works without JavaScript because the native input covers the whole area.

<ComponentPreview name="file-input-dropzone" />

## Accessibility

- Both are native `type="file"` inputs, so the file dialog, keyboard and screen readers work as
  usual.
- `FileDropzone`'s text is its label; its focus ring appears around the whole area.
- Check files on the server too: `accept` only filters the file dialog.

## API Reference

### FileInput

| Prop       | Type                   | Default |
| ---------- | ---------------------- | ------- |
| `accept`   | `string`               | —       |
| `multiple` | `boolean`              | `false` |
| `size`     | `"sm" \| "md" \| "lg"` | `"md"`  |
| `invalid`  | `boolean`              | `false` |

### FileDropzone

| Prop          | Type        | Default                            |
| ------------- | ----------- | ---------------------------------- |
| `title`       | `ReactNode` | "Click to upload or drag and drop" |
| `description` | `ReactNode` | —                                  |

Both forward native `<input>` attributes.
