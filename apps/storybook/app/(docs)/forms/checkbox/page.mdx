## Accessibility

- A native checkbox tinted with `accent-brand`, so the browser keeps drawing it, including in
  high-contrast and forced-colors modes.
- The label is linked with `htmlFor`, so clicking it toggles the checkbox; <kbd>Space</kbd>
  toggles it from the keyboard.
- Group related checkboxes in a `Fieldset` so screen readers announce the legend.
- `invalid` sets `aria-invalid` and a red outline; explain the problem in text as well.

## API Reference

### Checkbox

| Prop          | Type        | Default |
| ------------- | ----------- | ------- |
| `label`       | `ReactNode` | —       |
| `description` | `ReactNode` | —       |
| `bordered`    | `boolean`   | `false` |
| `invalid`     | `boolean`   | `false` |

All other `<input>` attributes are forwarded, such as `name`, `value` and `defaultChecked`.

### Fieldset

| Prop          | Type                         | Default      |
| ------------- | ---------------------------- | ------------ |
| `legend`      | `ReactNode` (required)       | —            |
| `hideLegend`  | `boolean`                    | `false`      |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` |

`className` styles the `<fieldset>`; `contentClassName` styles the element that lays out the
controls, for example a grid.
