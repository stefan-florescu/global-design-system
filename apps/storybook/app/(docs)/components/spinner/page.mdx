## Usage

```tsx
import { Spinner } from "@stefan-florescu/ui";
```

```tsx
<Spinner />
```

`Spinner` is an animated SVG: a grey track under a coloured arc that spins. It renders a
`role="status"` region with visually hidden text, "Loading…" by default, so screen readers hear
that something is loading. `className` styles that region, for example to position it.

## Examples

### Default spinner

The default spinner is 32px, with a `brand` arc over a `neutral-tertiary` track.

<ComponentPreview name="spinner-demo" />

### Colors

Set `variant` to `brand`, `dark`, `success`, `danger`, `warning`, `pink` or `purple`. The arc keeps
3:1 contrast against the track and the page in light and dark mode, so some colours use a stronger
role (see [Accessibility](#accessibility)).

<ComponentPreview name="spinner-colors" />

### Sizes

Set `size` to `xs` (16px), `sm` (24px), `md` (32px, the default), `lg` (40px) or `xl` (48px).

<ComponentPreview name="spinner-sizes" />

### Alignment

The spinner's SVG is inline, so align it with `text-start`, `text-center` or `text-end` on the
spinner or its parent. These logical utilities flip in right-to-left layouts.

<ComponentPreview name="spinner-alignment" />

### Spinner with card

Use a spinner when content inside a card is still loading. Position it with `className`, dim the
content and set `aria-busy="true"` on the card until it loads.

<ComponentPreview name="spinner-card" />

### Progress spinner

Use a small spinner in a list of steps to mark the one in progress. For a full multi-step process,
use the [Stepper](/components/stepper).

<ComponentPreview name="spinner-progress" />

### Buttons

`Button`'s `loading` state draws this spinner, disables the button and sets `aria-busy`. The
spinner takes the label colour, or `brand` on the secondary, tertiary and ghost buttons. See the
[button loader](/components/button#loader).

<ComponentPreview name="spinner-buttons" />

To put a spinner inside another element that already says it is busy, add `decorative`: only the
SVG is rendered, hidden from assistive technology, and `variant="current"` draws it in the text
colour, as in the [badge loader](/components/badge#badges-with-loader).

```tsx
<Badge variant="brand">
  <Spinner decorative variant="current" className="me-1" />2 mins ago
</Badge>
```

## Accessibility

- The spinner is a `role="status"` region with visually hidden text, and
  the SVG is `aria-hidden`. Use `label` to say what is loading, such as "Loading orders".
- A status region is announced when its text changes, not always when it first appears. Render the
  `Spinner` before the work starts and remove it when it ends, or put it inside a region that is
  already on the page. For the region that is updating, set `aria-busy="true"` while it loads.
- `decorative` renders the SVG alone, with no status region, for elements that already announce
  that they are busy, such as `Button` with `loading` (it sets `aria-busy` and keeps its label).
- The spin stops when the user prefers reduced motion (`motion-reduce:animate-none`); the arc and
  the status text still say it is loading. A loading indicator counts as essential motion under
  WCAG 2.2.2, so this goes beyond the minimum, as `Button` and `Skeleton` do.
- The arc is a meaningful graphic, so it keeps 3:1 against the track and the page (WCAG 1.4.11).
  Where a plain fill would fail that, the nearest passing role is used: `fg-brand`, `fg-success` and
  `fg-danger` (lighter in dark mode), `body` for the dark spinner in dark mode instead of
  `quaternary`, and `fg-warning-subtle` for warning (the plain `warning` fill is 2.6:1 in light
  mode). Pink and purple use the `fg-pink` and `fg-purple` roles.
- In the card example, the dimmed content is `aria-busy` while the spinner shows. In the progress
  example, finished steps say ", completed" as visually hidden text, since their check icons are
  hidden.

## API Reference

### Spinner

| Prop         | Type                                                                                                 | Default      |
| ------------ | ---------------------------------------------------------------------------------------------------- | ------------ |
| `variant`    | `"brand" \| "dark" \| "success" \| "danger" \| "warning" \| "pink" \| "purple" \| "current"`         | `"brand"`    |
| `size`       | `"xs" \| "sm" \| "md" \| "lg" \| "xl"`, or `null` to size it with CSS (for example `[&_svg]:size-4`) | `"md"`       |
| `label`      | `string`. Text for screen readers. Not with `decorative`.                                            | `"Loading…"` |
| `decorative` | `boolean`. Renders only the hidden SVG, with no status region.                                       | `false`      |
| `className`  | `string`. On the status region, or on the SVG when `decorative`.                                     | —            |

Other native attributes go on the `<div>` region, or on the `<svg>` when `decorative`, including
`ref`. `spinnerVariants()`, `spinnerTrackVariants()` and `spinnerArcVariants()` return the class
names for custom markup.
