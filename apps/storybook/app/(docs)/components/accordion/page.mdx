## Installation

<InstallCommand packages="@stefan-florescu/ui @stefan-florescu/tokens @stefan-florescu/themes" />

Then import the styles once in your global CSS, after Tailwind:

```css
@import "tailwindcss";
@import "@stefan-florescu/ui/styles.css";
```

## Usage

```tsx
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from "@stefan-florescu/ui";
```

```tsx
<Accordion defaultValue={["item-1"]}>
  <AccordionItem value="item-1">
    <AccordionTrigger>Is it accessible?</AccordionTrigger>
    <AccordionContent>Yes. It follows the WAI-ARIA Accordion pattern.</AccordionContent>
  </AccordionItem>
</Accordion>
```

`Accordion` is a client component. You can render it from a Server Component; only its own
JavaScript ships to the browser.

## Examples

### Default accordion

Opening an item closes the one that was open. Pressing an open item's title closes it. Open the
first item on load with `defaultValue`. The open title uses `neutral-secondary-medium` and
`heading`.

### Separated cards

Add `separated` to show each item as its own card, 1rem apart.

### Always open

Add `multiple` to keep several items open at once. This example also puts an icon before each
title.

<ComponentPreview name="accordion-multiple" />

### Color options

Set `variant="brand"` for Flowbite's blue hover: `brand-softer` with `fg-brand` text.

<ComponentPreview name="accordion-brand" />

### Flush accordion

Add `flush` to remove the box, background and side padding, leaving a `default` hairline under
every title and panel.

<ComponentPreview name="accordion-flush" />

### Arrow style

The chevron turns while its item is open. Pass `icon` to `AccordionTrigger` to show another icon,
which doesn't turn, or `icon={null}` for none.

<ComponentPreview name="accordion-arrow" />

### Nesting accordions

An accordion can sit inside another item's content. Lower the nested titles' `headingLevel` so the
page outline stays correct. Arrow keys move only between titles of the same accordion.

## Accessibility

- Follows the [WAI-ARIA Accordion pattern](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/).
- Each title is a native `<button>` inside a heading (`<h3>` by default; set `headingLevel` to
  match your page outline).
- The button has `aria-expanded` and `aria-controls`. The panel is a `region` labelled by its
  title, and is `hidden` while closed, so it is skipped by keyboard and screen readers.
- Flowbite has no keyboard focus style on titles; ours draws a solid 2px `ring` outline inside the
  title on keyboard focus.
- Icons are decorative (`aria-hidden`), and the chevron's rotation stops when the user prefers
  reduced motion.
- Every text and surface pairing (`body` and `heading` on `neutral-primary` and
  `neutral-secondary-medium`, `fg-brand` on `brand-softer`) passes WCAG 2.2 AA in both themes, as
  in Flowbite.

| Key                                 | Action                                             |
| ----------------------------------- | -------------------------------------------------- |
| <Kbd>Tab</Kbd>                      | Moves focus to the next focusable element          |
| <Kbd>Enter</Kbd> / <Kbd>Space</Kbd> | Opens or closes the focused item                   |
| <Kbd>↓</Kbd> / <Kbd>↑</Kbd>         | Moves focus to the next / previous title, wrapping |
| <Kbd>Home</Kbd> / <Kbd>End</Kbd>    | Moves focus to the first / last title              |

## API Reference

### Accordion

| Prop            | Type                        | Default     |
| --------------- | --------------------------- | ----------- |
| `multiple`      | `boolean`                   | `false`     |
| `defaultValue`  | `string[]`                  | `[]`        |
| `value`         | `string[]` (controlled)     | —           |
| `onValueChange` | `(value: string[]) => void` | —           |
| `variant`       | `"neutral" \| "brand"`      | `"neutral"` |
| `flush`         | `boolean`                   | `false`     |
| `separated`     | `boolean`                   | `false`     |
| `className`     | `string`                    | —           |

### AccordionItem

| Prop       | Type                | Default |
| ---------- | ------------------- | ------- |
| `value`    | `string` (required) | —       |
| `disabled` | `boolean`           | `false` |

### AccordionTrigger

| Prop           | Type                                                  | Default         |
| -------------- | ----------------------------------------------------- | --------------- |
| `headingLevel` | `2 \| 3 \| 4 \| 5 \| 6`                               | `3`             |
| `icon`         | `ReactNode`. Replaces the chevron; `null` removes it. | Turning chevron |

### AccordionContent

Accepts all `<div>` attributes.

All components forward their remaining native attributes, including `ref` and `className`.
