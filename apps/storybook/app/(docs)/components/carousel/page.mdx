## Usage

```tsx
import { Carousel } from "@stefan-florescu/ui";
```

```tsx
<Carousel aria-label="Featured trips">
  <img src="/trips/alps.jpg" alt="The Alps at sunrise" />
  <img src="/trips/coast.jpg" alt="A rocky coastline" />
</Carousel>
```

Each child is one slide. `Carousel` is a client component.

## Examples

### Default slider

Add `autoPlay` to move to the next slide every `interval` milliseconds (5000 by default). A pause
button appears in the corner. Rotation pauses while the pointer is over the carousel, and stops
when keyboard focus enters it until the user starts it again.

## Accessibility

- Follows the [WAI-ARIA Carousel pattern](https://www.w3.org/WAI/ARIA/apg/patterns/carousel/): a
  region with `aria-roledescription="carousel"` and your `aria-label`, and slides announced as
  "slide, 2 of 5".
- Hidden slides are `inert`, so their links and buttons can't receive focus.
- Slide changes are announced politely, except while the carousel rotates on its own.
- Automatic rotation always has a pause button, pauses on hover, stops on keyboard focus, and never
  starts when the user prefers reduced motion. The slide transition is also turned off for them.
- Previous, next and indicator buttons have names ("Next slide", "Go to slide 3"), and the current
  indicator has `aria-current`. Each indicator is a 24px target.
- Give every image slide meaningful `alt` text.

## API Reference

| Prop            | Type                      | Default      |
| --------------- | ------------------------- | ------------ |
| `autoPlay`      | `boolean`                 | `false`      |
| `interval`      | `number` (ms)             | `5000`       |
| `controls`      | `boolean`                 | `true`       |
| `indicators`    | `boolean`                 | `true`       |
| `defaultIndex`  | `number`                  | `0`          |
| `onSlideChange` | `(index: number) => void` | —            |
| `aria-label`    | `string`                  | `"Carousel"` |

All other `<section>` attributes are forwarded, including `ref` and `className`.
