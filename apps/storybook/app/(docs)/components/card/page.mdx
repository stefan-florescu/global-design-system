## Usage

```tsx
import { Card, CardDescription, CardTitle } from "@stefan-florescu/ui";
```

```tsx
<Card className="max-w-sm">
  <CardTitle>Noteworthy technology acquisitions 2021</CardTitle>
  <CardDescription>Here are the biggest technology acquisitions of 2025 so far.</CardDescription>
</Card>
```

Children sit in a `p-6` body. `CardTitle` is a 24px semibold title with a 12px gap below;
override its size or spacing with `className`, as the examples do.

## Accessibility

- A card is a plain container. Give it a heading with `CardTitle` (an `<h3>` by default; set
  `headingLevel` to match your page outline) so screen-reader users can jump between cards.
- With `href`, the whole card is one link whose name is all of its text. Keep link cards short,
  and don't put buttons or other links inside them: a link that contains a button is invalid
  HTML. The horizontal card is a plain card for this reason.
- Link cards draw a solid `ring` outline on keyboard focus.
- Images are decorative unless you pass `imgAlt`.
- The profile card's menu button is named "Actions for Bonnie Green", so it says what it acts on,
  draws a solid focus outline, and opens a WAI-ARIA menu: see
  [Dropdown](/components/dropdown) for its keyboard support.
- Card text uses `heading` and `body` on the `neutral-primary-soft` surface, which pass WCAG 2.2 AA
  in both themes.

## API Reference

### Card

| Prop         | Type      | Default |
| ------------ | --------- | ------- |
| `href`       | `string`  | —       |
| `horizontal` | `boolean` | `false` |
| `imgSrc`     | `string`  | —       |
| `imgAlt`     | `string`  | `""`    |

### CardTitle

| Prop           | Type                    | Default |
| -------------- | ----------------------- | ------- |
| `headingLevel` | `2 \| 3 \| 4 \| 5 \| 6` | `3`     |

`CardDescription` renders a `<p>` in `body`. All parts forward native attributes, including `ref`
and `className`.

| Token                      | Use                 |
| -------------------------- | ------------------- |
| `neutral-primary-soft`     | Card surface        |
| `default`                  | Border              |
| `neutral-secondary-medium` | Link card hover     |
| `heading` · `body`         | Title · description |
| `radius.base`              | Corners (12px)      |
| `shadow.xs`                | Elevation           |
