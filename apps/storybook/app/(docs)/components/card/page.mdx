## Usage

```tsx
import { Card, CardDescription, CardTitle } from "@stefan-florescu/ui";
```

```tsx
<Card>
  <CardTitle>Release notes</CardTitle>
  <CardDescription>What changed this week.</CardDescription>
</Card>
```

## Accessibility

- A card is a plain container. Give it a heading with `CardTitle` (an `<h3>` by default; set
  `headingLevel` to match your page outline) so screen-reader users can jump between cards.
- With `href`, the whole card is one link whose name is all of its text. Keep link cards short,
  and don't put buttons or other links inside them.
- Images are decorative unless you pass `imgAlt`.
- Card text uses `card-foreground` and `muted-foreground` on the `card` surface, which pass WCAG
  2.2 AA in both themes.

## API Reference

### Card

| Prop         | Type      | Default |
| ------------ | --------- | ------- |
| `href`       | `string`  | —       |
| `horizontal` | `boolean` | `false` |
| `imgSrc`     | `string`  | —       |
| `imgAlt`     | `string`  | `""`    |

### CardTitle

| Prop           | Type                    | Default |
| -------------- | ----------------------- | ------- |
| `headingLevel` | `2 \| 3 \| 4 \| 5 \| 6` | `3`     |

`CardDescription` renders a `<p>`. All parts forward native attributes, including `ref` and
`className`.
