## Usage

```tsx
import { Button, ButtonGroup } from "@stefan-florescu/ui";
```

```tsx
<ButtonGroup aria-label="Account">
  <Button variant="tertiary" size="sm">
    Profile
  </Button>
  <Button variant="tertiary" size="sm">
    Settings
  </Button>
</ButtonGroup>
```

`ButtonGroup` joins whatever `Button`s you put inside it: only the outer corners stay rounded,
neighbouring borders overlap into one line, and the group draws the shadow. Flowbite's grouped
buttons are `variant="tertiary"` at `size="sm"`.

## Accessibility

- Renders `role="group"`. Give it an `aria-label` that names the set, such as "Account" or "Text
  alignment", so screen readers announce it when focus enters.
- Every button stays a separate tab stop with its own name and keyboard behaviour.
- Flowbite marks counts and labels inside a group (`456k`, "Save book", the QR mark) as disabled
  buttons. Here they are `<span>`s hidden from assistive technology, and the meaning moves into the
  neighbouring button's name, so screen readers don't announce an unusable button: the badge
  group's menu button is named "Messages, 2 unread". Flowbite's "My files" button in the dropdown
  group is disabled for no reason, so here it is an ordinary button.
- Dropdown buttons in a group are [`Dropdown`](/components/dropdown) menu buttons: the arrow keys
  move through the items and Escape closes the menu and returns focus to the button. The "more"
  button has no visible text, so it is named "More options".
- Keyboard focus adds the solid `ring` outline to Flowbite's `ring-3` halo, and the focused button
  moves to the `z.raised` layer so the outline is never hidden behind a neighbour.
- Flowbite's tooltips on icon buttons are replaced by `aria-label`s until a tooltip component
  exists.
- A button group is for actions. To choose one option from a set, use a radio group or tabs,
  which announce the selected state.

## API Reference

| Prop          | Type                         | Default        |
| ------------- | ---------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `outline`     | `boolean`                    | `false`        |
| `pill`        | `boolean`                    | `false`        |
| `aria-label`  | `string`                     | —              |

All other `<div>` attributes are forwarded, including `ref` and `className`. Size and colour come
from the buttons inside; `outline` restyles them as Flowbite's outline group.
