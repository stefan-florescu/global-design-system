## Examples

### Default badges

Use badges to show counts or labels inside or outside other components. Choose the `variant` by
meaning: `brand` is the default, `alternative` and `gray` are neutral, and `danger`, `success` and
`warning` carry status.

<ComponentPreview name="badge-demo" />

| Variant       | Tokens                                                                |
| ------------- | --------------------------------------------------------------------- |
| `brand`       | `brand-softer` · `fg-brand-strong` text · `brand-subtle` border       |
| `alternative` | `neutral-primary-soft` · `heading` text · `default` border            |
| `gray`        | `neutral-secondary-medium` · `heading` text · `default-medium` border |
| `danger`      | `danger-soft` · `fg-danger-strong` text · `danger-subtle` border      |
| `success`     | `success-soft` · `fg-success-strong` text · `success-subtle` border   |
| `warning`     | `warning-soft` · `fg-warning` text · `warning-subtle` border          |

## Accessibility

- A badge is plain text in a `<span>` (or an `<a>` with `href`). Its content is its label, so
  write labels that make sense on their own.
- Don't rely on colour alone: "Failed" in a danger badge is clear; a red badge without text is not.
  Icon-only badges need visually hidden text.
- Every label and fill pairing passes WCAG 2.2 AA in light and dark, as in Flowbite.
- The remove button is a native `<button>` named "Remove". Use `dismissLabel` to say what is
  removed, such as "Remove React".
- Links and remove buttons draw a solid 2px `ring` outline on keyboard focus; Flowbite has none.
- Flowbite's notification and count badges use white text on `danger`; ours use
  `danger-foreground`, which is checked against `danger` on every token build.
- The loader and the dot are decorative and hidden from assistive technology. The spinner respects
  `prefers-reduced-motion`.

## API Reference

| Prop           | Type                                                                       | Default    |
| -------------- | -------------------------------------------------------------------------- | ---------- |
| `variant`      | `"brand" \| "alternative" \| "gray" \| "danger" \| "success" \| "warning"` | `"brand"`  |
| `size`         | `"sm" \| "lg"`                                                             | `"sm"`     |
| `bordered`     | `boolean`                                                                  | `false`    |
| `pill`         | `boolean`                                                                  | `false`    |
| `iconOnly`     | `boolean`. Add visually hidden text.                                       | `false`    |
| `dot`          | `boolean`                                                                  | `false`    |
| `href`         | `string`. Renders an `<a>`.                                                | —          |
| `onDismiss`    | `() => void`. Adds a remove button.                                        | —          |
| `dismissLabel` | `string`                                                                   | `"Remove"` |
| `className`    | `string`. Merged with `cn()`; your classes win.                            | —          |

All other native attributes are forwarded. `badgeVariants()` returns the class names for custom
elements.
