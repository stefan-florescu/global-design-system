## Usage

```tsx
import {
  Skeleton,
  SkeletonAvatar,
  SkeletonBlock,
  SkeletonImage,
  SkeletonLine,
  SkeletonVideo,
} from "@stefan-florescu/ui";
```

```tsx
<Skeleton className="max-w-sm">
  <SkeletonLine className="mb-4 w-48" />
  <SkeletonLine size="sm" className="mb-2.5" />
  <SkeletonLine size="sm" className="max-w-[330px]" />
</Skeleton>
```

`Skeleton` is the wrapper: a `role="status"` region that pulses and tells screen readers it is
loading. Lay out the placeholders inside it, sized like the content they stand for:

| Part             | Draws                                                                                          |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| `SkeletonLine`   | A line of text. `size="md"` (10px, the default) for headings, `size="sm"` (8px) for body text. |
| `SkeletonImage`  | A 192px block with an image icon.                                                              |
| `SkeletonVideo`  | A 192px block with a video icon.                                                               |
| `SkeletonAvatar` | A 32px user icon.                                                                              |
| `SkeletonBlock`  | Any other shape, such as a chart bar. Size and round it with `className`.                      |

## Accessibility

- As Flowbite recommends, the `Skeleton` wrapper is a `role="status"` region with visually hidden
  text, "Loading…" by default. Use `label` to say what is loading, such as "Loading articles".
- Every placeholder is `aria-hidden`, so screen readers skip the empty shapes.
- The pulse stops when the user prefers reduced motion (`motion-reduce:animate-none`). Set
  `animated={false}` to turn it off everywhere.
- Flowbite's card example nests a second `role="status"` inside the first; ours has one region, so
  "Loading" is announced once.
- Placeholders are decorative and exempt from contrast minimums. When the content arrives, replace
  the whole `Skeleton`; for a region that updates in place, set `aria-busy="true"` on it while it
  loads.

## API Reference

### Skeleton

| Prop        | Type                                            | Default      |
| ----------- | ----------------------------------------------- | ------------ |
| `label`     | `string`. Text for screen readers.              | `"Loading…"` |
| `animated`  | `boolean`. Pulses (not with reduced motion).    | `true`       |
| `className` | `string`. Merged with `cn()`; your classes win. | —            |

### SkeletonLine

| Prop        | Type                                             | Default |
| ----------- | ------------------------------------------------ | ------- |
| `size`      | `"sm" \| "md"`                                   | `"md"`  |
| `subtle`    | `boolean`. Uses the `default` fill.              | `false` |
| `className` | `string`. Set the width with `w-*` or `max-w-*`. | —       |

### SkeletonBlock

| Prop        | Type                                | Default |
| ----------- | ----------------------------------- | ------- |
| `subtle`    | `boolean`. Uses the `default` fill. | `false` |
| `className` | `string`. Set the size and radius.  | —       |

`SkeletonImage`, `SkeletonVideo` and `SkeletonAvatar` take `className` (for example `h-56` or
`size-7`). All parts forward other native attributes. `skeletonVariants()`,
`skeletonLineVariants()` and `skeletonBlockVariants()` return the class names for custom markup.
