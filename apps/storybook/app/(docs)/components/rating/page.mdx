## Accessibility

- `Rating` is a static image: `role="img"` named "Rated 4 out of 5" (change it with `label`). The
  stars inside are hidden from assistive technology. To let people choose a score, use radio
  buttons instead.
- When visible text next to the stars already states the score ("4.95 out of 5"), pass
  `aria-hidden` so it is not read twice, as in "Rating with text" and "Advanced rating".
- Stars are `fg-yellow` (yellow-400) when filled and `fg-disabled` when empty. In the
  light theme neither reaches the 3:1 non-text contrast of WCAG 1.4.11 against the page (about
  1.5:1 and 2.5:1), and no role token in the yellow family does without changing the look. Show
  the score as visible text next to the stars wherever the exact value matters; the text, not the
  colour, then carries the information.
- In "Advanced rating" and "Score rating" each bar is a [`Progress`](/components/progress) named by
  its row label ("5 star", "Staff") and valued with the visible figure, which is hidden from
  assistive technology so it is not read twice.
- The rating comment's title is an `<h3>` and the review's an `<h4>`; adjust the levels to fit the
  page they are placed in.
- The score badges ("8.7") read as "Score: 8.7" in "Review content". Links draw the solid `ring`
  outline on keyboard focus.

## API Reference

| Prop          | Type                   | Default                        |
| ------------- | ---------------------- | ------------------------------ |
| `value`       | `number`               | —                              |
| `max`         | `number`               | `5`                            |
| `size`        | `"sm" \| "md" \| "lg"` | `"sm"`                         |
| `label`       | `string`               | `"Rated {value} out of {max}"` |
| `aria-hidden` | `boolean`              | —                              |

All other `<div>` attributes are forwarded, including `ref` and `className`.

| Token         | Use          |
| ------------- | ------------ |
| `fg-yellow`   | Filled stars |
| `fg-disabled` | Empty stars  |
