## Usage

```tsx
import {
  Navbar,
  NavbarActions,
  NavbarBrand,
  NavbarCollapse,
  NavbarLink,
  NavbarToggle,
} from "@stefan-florescu/ui";
```

```tsx
<Navbar>
  <NavbarBrand href="/" name="Stefan DS" logo={<Layers />} />
  <NavbarActions>
    <Button size="sm">Get started</Button>
    <NavbarToggle />
  </NavbarActions>
  <NavbarCollapse>
    <NavbarLink href="/" active>
      Home
    </NavbarLink>
    <NavbarLink href="/about">About</NavbarLink>
  </NavbarCollapse>
</Navbar>
```

`Navbar` is the `<nav>` landmark and the centred row inside it. `NavbarBrand` links your logo and
name to the home page. `NavbarCollapse` holds the links: a list of `NavbarLink`s, and `<li>`s with a
`Dropdown` or a `MegaMenu`. Below `md` it is hidden until `NavbarToggle`, the hamburger button, shows
it; from `md` up the links sit in a row and the hamburger hides. `NavbarActions` keeps buttons such
as a call to action or a user menu at the end of the bar.

## Accessibility

- `Navbar` renders a `<nav>` landmark, named "Main" by default. Pass `aria-label` or
  `aria-labelledby` to name it, and give every navbar on a page a different name. Flowbite's navbars
  have no name.
- The hamburger follows the WAI-ARIA
  [disclosure navigation](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/examples/disclosure-navigation/)
  pattern: a `<button>` with `aria-expanded` and `aria-controls` that shows and hides the links in
  place, so <Kbd>Tab</Kbd> reaches them right after the button. Its name comes from `label`
  (visually hidden; default "Open main menu"); the icon is hidden from assistive technology.
- <Kbd>Escape</Kbd> in the open, collapsed menu hides it and returns focus to the hamburger. An open
  dropdown or mega menu inside takes <Kbd>Escape</Kbd> first. Flowbite has no <Kbd>Escape</Kbd>
  handling.
- The links are a list. `active` sets `aria-current="page"`; the current page is filled with `brand`
  in the collapsed menu and shown in `fg-brand` in the row. `disabled` removes the `href` and sets
  `aria-disabled`.
- Dropdowns of links are disclosures (`DropdownContent`): no `menu` role, <Kbd>Tab</Kbd> moves
  through the links. The multi-level, language and user menus are ARIA menus (`DropdownMenu`), moved
  through with the arrow keys, because they have sub-menus or act as one choice. See
  [Dropdown](/components/dropdown).
- Every link and button draws the solid `ring` outline on keyboard focus; Flowbite has none besides
  the hamburger's ring.
- Differences from Flowbite: links in a row are spaced with `gap` so right-to-left works without
  `rtl:space-x-reverse`; the search example uses two different ids (Flowbite reuses one) inside
  `role="search"` forms with labels; the language flags and the Flowbite logo are left out (we have
  no tokens for their colours), and a globe icon marks the language button; Flowbite's sticky
  example is `fixed`, ours is `sticky` inside a scrolling frame; the mega menu panel starts closed.

| Key                                 | Action                                                                 |
| ----------------------------------- | ---------------------------------------------------------------------- |
| <Kbd>Tab</Kbd>                      | Moves through the brand, links, dropdown buttons and actions in order. |
| <Kbd>Enter</Kbd> / <Kbd>Space</Kbd> | On the hamburger or a dropdown button, shows or hides its links.       |
| <Kbd>Escape</Kbd>                   | Closes an open dropdown, else hides the collapsed menu.                |

## API Reference

### Navbar

Forwards `nav` props; `className` goes on the `<nav>`.

| Prop           | Type                                                                                                | Default     |
| -------------- | --------------------------------------------------------------------------------------------------- | ----------- |
| `variant`      | `"default" \| "solid"`. Page-coloured or `neutral-secondary-soft` bar.                              | `"default"` |
| `border`       | `boolean`. A `default` line under the bar.                                                          | `true`      |
| `position`     | `"static" \| "sticky" \| "fixed"`. Sticky and fixed bars sit at the top, on `z.sticky` / `z.fixed`. | `"static"`  |
| `expand`       | `"md" \| "lg" \| "never"`. From this width the links show in a row and the hamburger hides.         | `"md"`      |
| `size`         | `"sm" \| "md"`. Inner padding: `md` for a navbar, `sm` for a secondary bar.                         | `"md"`      |
| `fluid`        | `boolean`. Span the full width instead of a centred `max-w-screen-xl` row.                          | `false`     |
| `open`         | `boolean`. Whether the collapsed links show (controlled).                                           | —           |
| `defaultOpen`  | `boolean`                                                                                           | `false`     |
| `onOpenChange` | `(open: boolean) => void`                                                                           | —           |
| `aria-label`   | `string`                                                                                            | `"Main"`    |

### NavbarBrand

| Prop   | Type                                                             | Default |
| ------ | ---------------------------------------------------------------- | ------- |
| `href` | `string`                                                         | —       |
| `name` | `ReactNode`. Shown next to the logo; the link's accessible name. | —       |
| `logo` | `ReactNode`. A mark such as an icon, 28px in `fg-brand`.         | —       |
| `src`  | `string`. A logo image, as an alternative to `logo`.             | —       |
| `alt`  | `string`                                                         | `""`    |

### NavbarToggle

Forwards `button` props.

| Prop    | Type                                    | Default            |
| ------- | --------------------------------------- | ------------------ |
| `label` | `string`. The button's accessible name. | `"Open main menu"` |
| `icon`  | `ReactNode`                             | `<Menu />`         |

### NavbarCollapse

Forwards `div` props; `className` goes on the collapsible region.

| Prop            | Type                                                                                         | Default     |
| --------------- | -------------------------------------------------------------------------------------------- | ----------- |
| `variant`       | `"default" \| "flush" \| "inline"`. Card, lines between rows, or a row that never collapses. | `"default"` |
| `header`        | `ReactNode`. Content above the links, such as a search field for small screens.              | —           |
| `listClassName` | `string`. Class names for the list.                                                          | —           |

### NavbarLink

Renders an `li` with an `a`, and forwards `a` props.

| Prop       | Type                                                       | Default |
| ---------- | ---------------------------------------------------------- | ------- |
| `active`   | `boolean`. The current page (`aria-current="page"`).       | `false` |
| `disabled` | `boolean`                                                  | `false` |
| `asChild`  | `boolean`. Render the only child, such as a router `Link`. | `false` |

### NavbarDropdownTrigger and NavbarActions

`NavbarDropdownTrigger` is a `Dropdown`'s button styled as a navbar link; it forwards `button` props
and takes `chevron` (default `true`). `NavbarActions` is a `div` that keeps its buttons at the end
of the bar from `expand` up.

| Token                    | Use                                                 |
| ------------------------ | --------------------------------------------------- |
| `neutral-primary`        | Bar (default)                                       |
| `neutral-secondary-soft` | Solid bar, collapsed menu card, toggle hover        |
| `default`, `light`       | Bar border, menu card border, flush row lines       |
| `heading`, `body`        | Brand name and links, hamburger icon                |
| `brand`, `fg-brand`      | Current page (filled when collapsed, text in a row) |
| `neutral-tertiary`       | Link hover in the collapsed menu, hamburger ring    |
| `radius.base`            | Menu card and hamburger corners                     |
| `z.sticky`, `z.fixed`    | Sticky and fixed bars                               |
