## Installation

<InstallCommand packages="@stefan-florescu/ui @stefan-florescu/tokens @stefan-florescu/themes" />

Then import the styles once in your global CSS, after Tailwind:

```css
@import "tailwindcss";
@import "@stefan-florescu/ui/styles.css";
```

## Usage

```tsx
import { Button } from "@stefan-florescu/ui";
```

```tsx
<Button>Get started</Button>
```

## Examples

### Default

Choose the variant by the intent of the action: `brand` is the main call to
action, `secondary` and `tertiary` support it, and `success`, `danger` and `warning` carry status.

<ComponentPreview name="button-variants" />

| Variant     | Tokens                                                            | Use it for                                                 |
| ----------- | ----------------------------------------------------------------- | ---------------------------------------------------------- |
| `brand`     | `brand` · `brand-strong` on hover · `brand-medium` focus halo     | The main call to action. The default; use one per view.    |
| `secondary` | `neutral-secondary-medium` · `default-medium` border · `body`     | A supporting action next to the main one.                  |
| `tertiary`  | `neutral-primary-soft` · `default` border · `body`                | A low-emphasis alternative, such as Cancel.                |
| `success`   | `success` · `success-strong` on hover                             | Confirming a positive outcome, such as Approve.            |
| `danger`    | `danger` · `danger-strong` on hover                               | Irreversible actions: delete, revoke, disconnect.          |
| `warning`   | `warning` · `warning-strong` on hover · `warning-foreground` text | An action that needs care but can be undone.               |
| `dark`      | `dark` · `dark-strong` on hover                                   | A high-emphasis neutral action.                            |
| `ghost`     | `heading` · `neutral-secondary-medium` on hover                   | Toolbars, menus and dense layouts where a fill adds noise. |

### Icon buttons

Add `iconOnly` for a square button: 32, 36 or 40px for `xs`, `sm` and `md`. An icon-only button has
no visible text, so it **must** have an `aria-label`.

<ComponentPreview name="button-icon" />

### Loader

`loading` shows a [spinner](/components/spinner), disables the button and sets `aria-busy`, while
keeping its colours. The spinner is drawn in the label colour, or in `brand` on the secondary,
tertiary and ghost buttons.
Keep the label so screen readers still announce what is happening. The spinner stops when the user
prefers reduced motion.

<ComponentPreview name="button-loading" />

## Accessibility

- Renders a native `<button>`. The default `type="button"` means it never submits a form by accident.
- Reachable with <Kbd>Tab</Kbd>; activates with <Kbd>Enter</Kbd> and <Kbd>Space</Kbd>.
- Focus shows a soft halo. Keyboard focus (`:focus-visible`) also draws a solid 2px `ring`
  outline, because the halo alone is under 3:1 against the page.
- Every label and fill pairing is checked against WCAG 2.2 AA in light and dark on each token
  build. The `warning` label is dark rather than white so it passes, and outline labels use the
  `fg-success`, `fg-danger` and `fg-warning` text colours.
- Icon-only buttons **must** have an `aria-label`. Decorative icons are `aria-hidden`.
- While loading, the button is disabled and `aria-busy="true"`; the spinner is hidden from
  assistive technology.
- The spinner respects `prefers-reduced-motion`.
- The smallest size (`xs`, 34px) meets the WCAG 2.5.8 minimum target size of 24×24px.
- Pattern: [WAI-ARIA Button](https://www.w3.org/WAI/ARIA/apg/patterns/button/).

| Key              | Action                    |
| ---------------- | ------------------------- |
| <Kbd>Tab</Kbd>   | Moves focus to the button |
| <Kbd>Enter</Kbd> | Activates the button      |
| <Kbd>Space</Kbd> | Activates the button      |

## API Reference

### Button

| Prop        | Type                                                                                              | Default    |
| ----------- | ------------------------------------------------------------------------------------------------- | ---------- |
| `variant`   | `"brand" \| "secondary" \| "tertiary" \| "success" \| "danger" \| "warning" \| "dark" \| "ghost"` | `"brand"`  |
| `outline`   | `boolean`. Only with `brand`, `secondary`, `success`, `danger` and `warning`.                     | `false`    |
| `size`      | `"xs" \| "sm" \| "md" \| "lg" \| "xl"`                                                            | `"md"`     |
| `pill`      | `boolean`                                                                                         | `false`    |
| `iconOnly`  | `boolean`. Requires `aria-label`.                                                                 | `false`    |
| `fullWidth` | `boolean`                                                                                         | `false`    |
| `loading`   | `boolean`                                                                                         | `false`    |
| `disabled`  | `boolean`                                                                                         | `false`    |
| `type`      | `"button" \| "submit" \| "reset"`                                                                 | `"button"` |
| `className` | `string`. Merged with `cn()`; your classes win.                                                   | —          |

All other native `<button>` attributes are forwarded, including `ref`.

### buttonVariants

```tsx
buttonVariants(options?: {
  variant?, outline?, size?, pill?, iconOnly?, fullWidth?, className?
}): string
```

Returns the button's class names, so you can style another element, such as a link, as a button.
