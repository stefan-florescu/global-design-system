## Installation

<InstallCommand packages="@stefan-florescu/ui @stefan-florescu/tokens @stefan-florescu/themes" />

Then import the styles once in your global CSS, after Tailwind:

```css
@import "tailwindcss";
@import "@stefan-florescu/ui/styles.css";
```

## Usage

```tsx
import { Button } from "@stefan-florescu/ui";
```

```tsx
<Button>Get started</Button>
```

## Examples

### Default

Choose the variant by the intent of the action, not by the colour you want. Each variant reads
its fill and label from the semantic colour tokens, so it follows the active theme.

<ComponentPreview name="button-variants" />

| Variant       | Tokens                                   | Use it for                                                 |
| ------------- | ---------------------------------------- | ---------------------------------------------------------- |
| `brand`       | `brand` · `brand-foreground`             | The main call to action. The default; use one per view.    |
| `primary`     | `primary` · `primary-foreground`         | A high-emphasis neutral action, such as Save in a toolbar. |
| `secondary`   | `secondary` · `secondary-foreground`     | A supporting action next to a primary one.                 |
| `outline`     | `border` · `background` · `foreground`   | A low-emphasis alternative, such as Cancel.                |
| `ghost`       | `accent` · `accent-foreground` on hover  | Toolbars, menus and dense layouts where a fill adds noise. |
| `success`     | `success` · `success-foreground`         | Confirming a positive outcome, such as Approve or Publish. |
| `warning`     | `warning` · `warning-foreground`         | An action that needs care but can be undone.               |
| `destructive` | `destructive` · `destructive-foreground` | Irreversible actions: delete, revoke, disconnect.          |
| `info`        | `info` · `info-foreground`               | A neutral, informational action, such as View details.     |
| `link`        | `primary`                                | An action that should read as inline text.                 |

### Pills

Add `pill` to round the ends with `radius.full`.

<ComponentPreview name="button-pill" />

### Outline

Add `outline` to draw a filled intent as an outline: a transparent fill, with a border and label in
the intent's `-subtle-foreground` colour and its `-subtle` surface on hover. Those pairings pass
WCAG 2.2 AA in both themes. `outline` applies to `brand`, `primary`, `success`, `warning`,
`destructive` and `info`.

<ComponentPreview name="button-outline" />

### Sizes

Five sizes on the 4px spacing scale, from `xs` (32px) to `xl` (52px). `md` is the default.

<ComponentPreview name="button-sizes" />

| Size | Height | Padding (inline) | Text   | Icon |
| ---- | ------ | ---------------- | ------ | ---- |
| `xs` | 32px   | `space.3`        | `xs`   | 14px |
| `sm` | 36px   | `space.3`        | `sm`   | 16px |
| `md` | 40px   | `space.5`        | `sm`   | 16px |
| `lg` | 48px   | `space.5`        | `base` | 20px |
| `xl` | 52px   | `space.6`        | `base` | 20px |

### Icon buttons

Add `iconOnly` for a square button. An icon-only button has no visible text, so it **must** have

### Loading

`loading` shows a spinner, disables the button and sets `aria-busy`. Keep the label so screen
readers still announce what is happening. The spinner stops when the user prefers reduced motion.

## Accessibility

- Renders a native `<button>`. The default `type="button"` means it never submits a form by accident.
- Reachable with <kbd>Tab</kbd>; activates with <kbd>Enter</kbd> and <kbd>Space</kbd>.
- A 2px `ring` focus ring, offset from the button, appears on keyboard focus (`:focus-visible`) and
  clears 3:1 against the background in both themes.
- Every label and fill pairing is checked against WCAG 2.2 AA in light and dark on each token
  build.
- Icon-only buttons **must** have an `aria-label`. Decorative icons are `aria-hidden`.
- While loading, the button is disabled and `aria-busy="true"`; the spinner is hidden from
  assistive technology.
- Transitions and the spinner respect `prefers-reduced-motion`.
- The smallest size (`xs`, 32px) meets the WCAG 2.5.8 minimum target size of 24×24px.
- Pattern: [WAI-ARIA Button](https://www.w3.org/WAI/ARIA/apg/patterns/button/).

| Key              | Action                    |
| ---------------- | ------------------------- |
| <kbd>Tab</kbd>   | Moves focus to the button |
| <kbd>Enter</kbd> | Activates the button      |
| <kbd>Space</kbd> | Activates the button      |

## API Reference

### Button

| Prop        | Type                                                                                                                         | Default    |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------- | ---------- |
| `variant`   | `"brand" \| "primary" \| "secondary" \| "outline" \| "ghost" \| "success" \| "warning" \| "destructive" \| "info" \| "link"` | `"brand"`  |
| `outline`   | `boolean`. Only with `brand`, `primary`, `success`, `warning`, `destructive` and `info`.                                     | `false`    |
| `size`      | `"xs" \| "sm" \| "md" \| "lg" \| "xl"`                                                                                       | `"md"`     |
| `pill`      | `boolean`                                                                                                                    | `false`    |
| `iconOnly`  | `boolean`. Requires `aria-label`.                                                                                            | `false`    |
| `fullWidth` | `boolean`                                                                                                                    | `false`    |
| `loading`   | `boolean`                                                                                                                    | `false`    |
| `disabled`  | `boolean`                                                                                                                    | `false`    |
| `type`      | `"button" \| "submit" \| "reset"`                                                                                            | `"button"` |
| `className` | `string`. Merged with `cn()`; your classes win.                                                                              | —          |

All other native `<button>` attributes are forwarded, including `ref`.

### buttonVariants

```tsx
buttonVariants(options?: {
  variant?, outline?, size?, pill?, iconOnly?, fullWidth?, className?
}): string
```

Returns the button's class names, so you can style another element, such as a link, as a button.
