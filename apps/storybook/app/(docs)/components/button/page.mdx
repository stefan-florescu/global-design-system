## Accessibility

- Renders a native `<button>` with `type="button"` by default, so it never submits a form by accident.
- Reachable with <kbd>Tab</kbd>; activates with <kbd>Enter</kbd> and <kbd>Space</kbd>.
- A visible focus ring appears on keyboard focus only (`:focus-visible`).
- Icon-only buttons **must** have an `aria-label`. Decorative icons are `aria-hidden`.
- While loading, set `disabled` and `aria-busy="true"` and keep a text label.
- Pattern: [WAI-ARIA Button](https://www.w3.org/WAI/ARIA/apg/patterns/button/).

## API Reference

| Prop        | Type                                                                          | Default     |
| ----------- | ----------------------------------------------------------------------------- | ----------- |
| `variant`   | `"primary" \| "secondary" \| "destructive" \| "outline" \| "ghost" \| "link"` | `"primary"` |
| `size`      | `"sm" \| "md" \| "lg" \| "icon"`                                              | `"md"`      |
| `type`      | `"button" \| "submit" \| "reset"`                                             | `"button"`  |
| `disabled`  | `boolean`                                                                     | `false`     |
| `className` | `string`                                                                      | —           |

All other native `<button>` attributes are forwarded, including `ref`.
