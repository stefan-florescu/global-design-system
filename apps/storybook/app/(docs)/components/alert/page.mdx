## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from "@stefan-florescu/ui";
```

```tsx
<Alert variant="success">
  <AlertTitle>Changes saved</AlertTitle>
  <AlertDescription>Your profile is up to date.</AlertDescription>
</Alert>
```

## Examples

### Default alert

Use alerts to give feedback on the current page or task. Choose the `variant` by meaning:
`brand` (the default) is for information, and `dark` is a neutral gray alert.

<ComponentPreview name="alert-demo" />

| Variant   | Tokens                                                                | Use it for                                     |
| --------- | --------------------------------------------------------------------- | ---------------------------------------------- |
| `brand`   | `brand-softer` · `fg-brand-strong` text · `brand-subtle` border       | Information or a tip. The default.             |
| `danger`  | `danger-soft` · `fg-danger-strong` text · `danger-subtle` border      | An error or a failed action the user must fix. |
| `success` | `success-soft` · `fg-success-strong` text · `success-subtle` border   | Confirming that an action worked.              |
| `warning` | `warning-soft` · `fg-warning` text · `warning-subtle` border          | Something that needs attention.                |
| `dark`    | `neutral-secondary-medium` · `heading` text · `default-medium` border | A low-emphasis note without a status.          |

## Accessibility

- `danger` and `warning` alerts have `role="alert"`, so screen readers announce them as soon as
  they appear. The other variants use the polite `role="status"`. Pass `role` to override, for
  example `role="note"` for static content.
- Render an alert when its message becomes relevant. Content inside a live region that is already
  on the page when it loads may not be announced.
- Icons are decorative and hidden from assistive technology; the text carries the meaning. Every
  label and fill pairing passes WCAG 2.2 AA in light and dark.
- The close button is a native `<button>` named "Dismiss" (change it with `dismissLabel`). It
  shows a soft focus ring and adds a solid 2px `ring` outline on keyboard focus, because
  the soft ring alone is under 3:1 against the alert.
- The buttons in "Additional content" use `Button`, so their labels use on-fill foreground tokens
  that pass contrast on each fill; the `dark` alert's button is the `dark` button.
- Pattern: [WAI-ARIA Alert](https://www.w3.org/WAI/ARIA/apg/patterns/alert/).

## API Reference

### Alert

| Prop           | Type                                                       | Default     |
| -------------- | ---------------------------------------------------------- | ----------- |
| `variant`      | `"brand" \| "danger" \| "success" \| "warning" \| "dark"`  | `"brand"`   |
| `icon`         | `ReactNode`. Decorative; hidden from assistive technology. | —           |
| `bordered`     | `boolean`                                                  | `false`     |
| `accentBorder` | `boolean`                                                  | `false`     |
| `dismissible`  | `boolean`                                                  | `false`     |
| `dismissLabel` | `string`                                                   | `"Dismiss"` |
| `onDismiss`    | `() => void`                                               | —           |
| `className`    | `string`. Merged with `cn()`; your classes win.            | —           |

`AlertTitle` renders a `<p>` and `AlertDescription` a `<div>`. All parts forward native attributes,
including `ref` and `className`. `alertVariants()` returns the class names of the alert surface.
