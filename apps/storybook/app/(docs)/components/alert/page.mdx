## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from "@stefan-florescu/ui";
```

```tsx
<Alert variant="success">
  <AlertTitle>Changes saved</AlertTitle>
  <AlertDescription>Your profile is up to date.</AlertDescription>
</Alert>
```

## Examples

### Default

Choose the variant by meaning. Each one uses its intent's `-subtle` surface and
`-subtle-foreground` text, a pairing checked for WCAG 2.2 AA in both themes.

<ComponentPreview name="alert-demo" />

| Variant       | Use it for                                          |
| ------------- | --------------------------------------------------- |
| `info`        | Neutral information or a tip. The default.          |
| `success`     | Confirming that an action worked.                   |
| `warning`     | Something that needs attention but is not blocking. |
| `destructive` | An error or a failed action the user must fix.      |
| `neutral`     | A low-emphasis note without a status.               |

## Accessibility

- `destructive` and `warning` alerts have `role="alert"`, so screen readers announce them as soon
  as they appear. The other variants use the polite `role="status"`. Pass `role` to override,
  for example `role="note"` for static content.
- Render an alert when its message becomes relevant. Content inside a live region that is already
  on the page when it loads may not be announced.
- Icons are decorative and hidden from assistive technology; the text carries the meaning.
- The close button is a native `<button>` named "Dismiss" (change it with `dismissLabel`), with a
  visible focus ring.
- Pattern: [WAI-ARIA Alert](https://www.w3.org/WAI/ARIA/apg/patterns/alert/).

## API Reference

### Alert

| Prop           | Type                                                             | Default     |
| -------------- | ---------------------------------------------------------------- | ----------- |
| `variant`      | `"info" \| "success" \| "warning" \| "destructive" \| "neutral"` | `"info"`    |
| `icon`         | `ReactNode`                                                      | —           |
| `bordered`     | `boolean`                                                        | `false`     |
| `accentBorder` | `boolean`                                                        | `false`     |
| `dismissible`  | `boolean`                                                        | `false`     |
| `dismissLabel` | `string`                                                         | `"Dismiss"` |
| `onDismiss`    | `() => void`                                                     | —           |

`AlertTitle` renders a `<p>` and `AlertDescription` a `<div>`. All parts forward native attributes,
including `ref` and `className`.
