## Usage

```tsx
import { Banner } from "@stefan-florescu/ui";
```

```tsx
<Banner dismissible>New: dark mode is here.</Banner>
```

The examples render inside a frame that stands in for the browser window. In your app, the banner
is fixed to the viewport.

<Callout title="Layering">
  `Banner` sits on the `z.fixed` layer (`z-fixed`), above sticky headers and below overlays, dialogs
  and toasts. See [Spacing & layout](/foundation/spacing-and-layout#layering).
</Callout>

## Examples

### Default sticky banner

A `neutral-primary-soft` bar fixed to the top of the viewport, with a message, an icon and a link.
Add `dismissible` to let people close it.

### Bottom banner position

Set `position="bottom"` to pin the banner to the bottom of the page instead.

### Marketing CTA banner

Add `floating` for Flowbite's marketing card: inset from the edges, with a border, `rounded-base`
corners and `shadow-xs`. It is at most `max-w-7xl` wide from the `lg` breakpoint.

<ComponentPreview name="banner-cta" />

### Newsletter sign-up banner

A banner can hold a short inline form, such as an email sign-up.

<ComponentPreview name="banner-newsletter" />

### Informational banner

Combine a heading, a description and a call to action. This example uses the
`neutral-secondary-soft` surface, as Flowbite does, through `className`.

<ComponentPreview name="banner-informational" />

### Position

`position="static"` places the banner in the normal page flow, for example at the top of a
layout that already scrolls.

Flowbite's marketing banner shows its brand logo; the example uses the product name instead.

## Accessibility

- The banner is a `<section>` labelled "Announcement", so it is listed as a region landmark.
  Pass `aria-label` to describe it better, for example "Cookie notice".
- It is not a live region: content that is on the page when it loads isn't announced. Use
  `Alert` for messages that react to what the user just did.
- The close button is a native `<button>` named "Close banner" (change it with `dismissLabel`).
  Flowbite gives it no focus style; ours draws a solid 2px `ring` outline on keyboard focus.
  Use `onDismiss` to remember the choice so the banner doesn't return on every page.
- The "Sign Up" and "Subscribe" buttons use `Button`, so their labels use `brand-foreground`
  rather than Flowbite's white, and form fields use the `input` border, which reaches 3:1.
- A fixed banner covers part of the page. Add matching padding to your layout so no content is
  hidden behind it.

## API Reference

| Prop           | Type                                            | Default          |
| -------------- | ----------------------------------------------- | ---------------- |
| `position`     | `"top" \| "bottom" \| "static"`                 | `"top"`          |
| `floating`     | `boolean`                                       | `false`          |
| `dismissible`  | `boolean`                                       | `false`          |
| `dismissLabel` | `string`                                        | `"Close banner"` |
| `onDismiss`    | `() => void`                                    | —                |
| `aria-label`   | `string`                                        | `"Announcement"` |
| `className`    | `string`. Merged with `cn()`; your classes win. | —                |

All other `<section>` attributes are forwarded, including `ref`. Children are laid out in a
row with `justify-between`; the close button comes last.
