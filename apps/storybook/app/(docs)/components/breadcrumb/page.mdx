## Usage

```tsx
import { Breadcrumb, BreadcrumbItem } from "@stefan-florescu/ui";
```

```tsx
<Breadcrumb>
  <BreadcrumbItem href="/" icon={<House aria-hidden />}>
    Home
  </BreadcrumbItem>
  <BreadcrumbItem href="/projects">Projects</BreadcrumbItem>
  <BreadcrumbItem>Flowbite</BreadcrumbItem>
</Breadcrumb>
```

## Accessibility

- Renders a `<nav>` landmark named "Breadcrumb" (change it with `aria-label`) containing an
  ordered list, as in the WAI-ARIA Breadcrumb pattern.
- The last item, without `href`, has `aria-current="page"` and is not a link.
- Chevron separators and icons are decorative and hidden from assistive technology. Separators
  flip in right-to-left layouts.
- Links draw a solid `ring` outline on keyboard focus; Flowbite has no focus style.
- Links (`body`) and the current page (`body-subtle`) pass WCAG 2.2 AA on the page and on the solid
  surface in both themes.
- Pattern: [WAI-ARIA Breadcrumb](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/).

## API Reference

### Breadcrumb

| Prop         | Type                   | Default        |
| ------------ | ---------------------- | -------------- |
| `variant`    | `"default" \| "solid"` | `"default"`    |
| `aria-label` | `string`               | `"Breadcrumb"` |

### BreadcrumbItem

| Prop   | Type        | Default |
| ------ | ----------- | ------- |
| `href` | `string`    | —       |
| `icon` | `ReactNode` | —       |

All parts forward native attributes, including `ref` and `className`.

| Token                      | Use                  |
| -------------------------- | -------------------- |
| `body`                     | Links and separators |
| `fg-brand`                 | Link hover           |
| `body-subtle`              | Current page         |
| `neutral-secondary-medium` | Solid surface        |
| `default-medium`           | Solid border         |
| `radius.base`              | Solid corners (12px) |
