## Usage

```tsx
import { Breadcrumb, BreadcrumbItem } from "@stefan-florescu/ui";
```

```tsx
<Breadcrumb>
  <BreadcrumbItem href="/">Home</BreadcrumbItem>
  <BreadcrumbItem href="/projects">Projects</BreadcrumbItem>
  <BreadcrumbItem>Design system</BreadcrumbItem>
</Breadcrumb>
```

## Accessibility

- Renders a `<nav>` landmark named "Breadcrumb" (change it with `aria-label`) containing an
  ordered list, as in the WAI-ARIA Breadcrumb pattern.
- The last item, without `href`, has `aria-current="page"` and is not a link.
- Chevron separators and icons are decorative and hidden from assistive technology.
- Links show a focus ring on keyboard focus.
- Pattern: [WAI-ARIA Breadcrumb](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/).

## API Reference

### Breadcrumb

| Prop         | Type                   | Default        |
| ------------ | ---------------------- | -------------- |
| `variant`    | `"default" \| "solid"` | `"default"`    |
| `aria-label` | `string`               | `"Breadcrumb"` |

### BreadcrumbItem

| Prop   | Type        | Default |
| ------ | ----------- | ------- |
| `href` | `string`    | —       |
| `icon` | `ReactNode` | —       |

All parts forward native attributes, including `ref` and `className`.
