## Usage

```tsx
import { Avatar, ChatBubble, ChatBubbleMenu, ChatBubbleMenuItem } from "@stefan-florescu/ui";
```

```tsx
<ChatBubble
  avatar={<Avatar src="/team/bonnie.jpg" alt="" size="sm" />}
  name="Bonnie Green"
  time="11:46"
  dateTime="2026-10-08T11:46"
  status="Delivered"
  actions={
    <ChatBubbleMenu>
      <ChatBubbleMenuItem>Reply</ChatBubbleMenuItem>
    </ChatBubbleMenu>
  }
>
  That's awesome. I think our users will really appreciate the improvements.
</ChatBubble>
```

`ChatBubble` lays out the avatar, the sender's name and time, the message, the status and the
actions. Anything can go inside it: text, a voice note, a file, images or a link preview.

## Accessibility

- Put conversations in a `role="log"` container with a name, such as "Chat with Bonnie Green". New
  messages added to the end are announced politely.
- The time renders a `<time>` element; pass `dateTime` so it has a machine-readable value.
- When the sender's name is shown, give the avatar an empty `alt` so the name isn't read twice.
- `ChatBubbleMenu` is a [`Dropdown`](/components/dropdown) menu and follows the
  [WAI-ARIA menu button](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/) pattern. The
  "more" button is named "Message actions" (change it with `label`) and has `aria-haspopup="menu"`
  and `aria-expanded`; the actions are `menuitem`s. <Kbd>Enter</Kbd>, <Kbd>Space</Kbd> or
  <Kbd>Arrow Down</Kbd> open it on the first action (<Kbd>Arrow Up</Kbd> on the last), the arrow
  keys, <Kbd>Home</Kbd>, <Kbd>End</Kbd> and typing move between actions, and choosing one or
  pressing <Kbd>Esc</Kbd> closes it and returns focus to the button. Keyboard focus shows a solid
  `ring` outline as well as Flowbite's halo. Flowbite's dots dropdown is a list of links with no
  menu roles or arrow-key support.
- Image download buttons also appear when they receive keyboard focus, not only on hover, and every
  icon-only button has a name, such as "Pause voice note" or "Download Flowbite Terms &
  Conditions". Flowbite's "Download image" tooltips on the image download buttons are
  [`Tooltip`](/components/tooltips)s that describe the button, so screen readers read the specific
  name first ("Download Green hills at noon") and the tooltip after it. They open on hover and on
  keyboard focus, and <Kbd>Escape</Kbd> hides them.
- Text uses `heading` and `body` on `neutral-secondary-soft`, pairings that pass WCAG 2.2 AA in
  both themes. Flowbite's white labels on images use `dark-foreground`, and the hover overlay uses
  `dark-backdrop` instead of a raw gray.

## API Reference

### ChatBubble

| Prop       | Type                                | Default     |
| ---------- | ----------------------------------- | ----------- |
| `avatar`   | `ReactNode`                         | —           |
| `name`     | `ReactNode`                         | —           |
| `time`     | `string`                            | —           |
| `dateTime` | `string`                            | —           |
| `status`   | `ReactNode`                         | —           |
| `actions`  | `ReactNode`, such as a menu         | —           |
| `variant`  | `"default" \| "outline" \| "clean"` | `"default"` |
| `align`    | `"start" \| "end"`                  | `"start"`   |

All other `<div>` attributes are forwarded, including `ref` and `className`.

### ChatBubbleMenu

| Prop           | Type                                                    | Default             |
| -------------- | ------------------------------------------------------- | ------------------- |
| `label`        | `string`. The "more" button's name.                     | `"Message actions"` |
| `placement`    | `Dropdown` placement, such as `"bottom"` or `"top-end"` | `"bottom-start"`    |
| `open`         | `boolean`. Controls the open state.                     | —                   |
| `defaultOpen`  | `boolean`                                               | `false`             |
| `onOpenChange` | `(open: boolean) => void`                               | —                   |
| `children`     | `ChatBubbleMenuItem` elements                           | —                   |

Other attributes go to the menu (`DropdownMenu`, `w-40` like Flowbite's). `ChatBubbleMenuItem` is
a `DropdownItem`: a `menuitem` button, or a link with `href`, that closes the menu when chosen. It
takes every `DropdownItem` prop, such as `onClick`, `variant="danger"` or `disabled`. Other
`Dropdown` parts, such as `DropdownDivider`, can go between the items.
