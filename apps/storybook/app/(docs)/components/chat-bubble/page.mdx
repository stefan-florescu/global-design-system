## Usage

```tsx
import { Avatar, ChatBubble } from "@stefan-florescu/ui";
```

```tsx
<ChatBubble
  avatar={<Avatar src="/team/ana.jpg" alt="" size="sm" />}
  name="Ana Popescu"
  time="11:46"
  dateTime="2026-10-08T11:46"
  status="Delivered"
>
  The new tokens are live.
</ChatBubble>
```

## Accessibility

- Put conversations in a `role="log"` container with a name, such as "Chat with Ana Popescu". New
  messages added to the end are announced politely.
- The time renders a `<time>` element; pass `dateTime` so it has a machine-readable value.
- When the sender's name is shown, give the avatar an empty `alt` so the name isn't read twice.
- Text uses `foreground` and `muted-foreground` on `muted` or `background`, pairings that pass WCAG
  2.2 AA in both themes.
- Name icon-only actions inside a bubble, such as "Download Design tokens guide".

## API Reference

| Prop       | Type                                | Default     |
| ---------- | ----------------------------------- | ----------- |
| `avatar`   | `ReactNode`                         | —           |
| `name`     | `ReactNode`                         | —           |
| `time`     | `string`                            | —           |
| `dateTime` | `string`                            | —           |
| `status`   | `ReactNode`                         | —           |
| `variant`  | `"default" \| "outline" \| "clean"` | `"default"` |
| `align`    | `"start" \| "end"`                  | `"start"`   |

All other `<div>` attributes are forwarded, including `ref` and `className`.
