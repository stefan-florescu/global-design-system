```css
@import "tailwindcss";

```

## Usage

```tsx
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@stefan-florescu/ui";
```

```tsx
<Drawer>
  <DrawerTrigger>Show drawer</DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Drawer heading</DrawerTitle>
      <DrawerClose />
    </DrawerHeader>
    <DrawerDescription>Anything you want to show next to the page.</DrawerDescription>
  </DrawerContent>
</Drawer>
```

To open it from your own state, make it controlled:

```tsx
const [open, setOpen] = useState(false);

<Drawer open={open} onOpenChange={setOpen}>
  <DrawerContent>…</DrawerContent>
</Drawer>;
```

close button, <kbd>Esc</kbd> and a click on the backdrop close it. `DrawerTitle` names the dialog

## Backdrop

The backdrop dims the page while the drawer is open, and a click on it closes the drawer. Set
`backdrop={false}` to remove it.

### Enabled (default)

With the backdrop, the drawer is a **modal** dialog: the rest of the page is inert until it
closes, and <kbd>Tab</kbd> stays inside the drawer.

<ComponentPreview name="drawer-backdrop" />

### Disabled

Without the backdrop, the drawer is a **non-modal** dialog: the page stays usable, a click outside
doesn't close it, and <kbd>Tab</kbd> can leave it. <kbd>Esc</kbd> still closes it while focus is
inside.

<ComponentPreview name="drawer-no-backdrop" />

## Swipeable edge

Add `edge` to keep the top of a bottom drawer on screen while it is closed. Put a `DrawerHandle`
first in `DrawerContent`: it shows Flowbite's grip, names the drawer, and opens or closes it when
pressed. The 60px strip it sits in stays fixed to the bottom of the screen; in this preview it is
kept inside the example.

## Accessibility

- Follows the WAI-ARIA [dialog (modal)](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)
  pattern with the native `<dialog>` and `showModal()`: the drawer sits in the top layer, the rest
  of the page is inert, so <kbd>Tab</kbd> only reaches the drawer (and the browser's own controls).
- On open, focus moves to the first focusable element in the drawer (its close button). Add
  `autoFocus` to another element to start there instead. On close, focus returns to the trigger.
- `DrawerTitle` (or `DrawerHandle`) names the dialog with `aria-labelledby`, and
  `DrawerDescription` describes it with `aria-describedby`. A drawer without a title needs an
  `aria-label` on `DrawerContent`.
- `DrawerTrigger` has `aria-haspopup="dialog"`, `aria-expanded` and `aria-controls`.
  `DrawerHandle` is a button with `aria-expanded`.
- The close button is labelled "Close" (pass `label` for something more specific). Keyboard focus
  draws a solid `ring` outline on the close button, the handle and the trigger.
- The slide follows Flowbite's 150ms timing and is turned off when the user prefers reduced
  motion.
- Differences from Flowbite:
  - The drawer is a `dialog` that traps focus and makes the page inert; Flowbite's is a `div` that
    keeps the page in the tab order. Without a backdrop it is a non-modal `dialog`.
  - The title is an `h2`, not an `h5`, so it doesn't skip heading levels.
  - In the swipeable edge, the closed drawer's strip shows only the handle; the rest of the drawer
    is not rendered until it opens, so it is never reachable off screen.
  - Navigation items, the disclosure and the widget tiles in the examples draw a focus outline.

| Key                                                | Action                                                  |
| -------------------------------------------------- | ------------------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> on the trigger | Opens the drawer and moves focus into it                |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd>   | Moves through the drawer (stays inside with a backdrop) |
| <kbd>Esc</kbd>                                     | Closes the drawer and returns focus                     |

## API Reference

### Drawer

The root. It holds the state and renders no element.

| Prop           | Type                                       | Default  |
| -------------- | ------------------------------------------ | -------- |
| `open`         | `boolean`. Controlled.                     | —        |
| `defaultOpen`  | `boolean`. Uncontrolled.                   | `false`  |
| `onOpenChange` | `(open: boolean) => void`                  | —        |
| `placement`    | `"left" \| "right" \| "top" \| "bottom"`   | `"left"` |
| `backdrop`     | `boolean`. Modal with a backdrop.          | `true`   |
| `scrollLock`   | `boolean`. Stops the page scrolling.       | `true`   |
| `edge`         | `boolean`. Swipeable edge (always bottom). | `false`  |

### DrawerTrigger

A `Button` that opens the drawer. Takes every `Button` prop (`variant`, `size`…).

### DrawerContent

The `<dialog>` panel. Set its width with `className` (`w-96` by default for side drawers). All other
`<dialog>` attributes are forwarded, including `ref`.

### DrawerHeader, DrawerTitle, DrawerDescription

A heading row with a divider, an `h2` and a `p`. They forward their element's attributes.

### DrawerClose

| Prop    | Type                           | Default   |
| ------- | ------------------------------ | --------- |
| `label` | `string`. The accessible name. | `"Close"` |

### DrawerHandle

The swipeable edge's grip button. Its children are the drawer's title.

### useDrawer

```tsx
const { open, setOpen } = useDrawer();
```

Opens or closes the drawer from any element inside `<Drawer>`.
