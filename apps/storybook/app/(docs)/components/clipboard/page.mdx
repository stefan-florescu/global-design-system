`Clipboard` is a client component built on `Button`, so it accepts the same `variant`, `size`,
`pill` and `iconOnly` options.

## Accessibility

- A native `<button>`. Its name is `label` ("Copy" by default) and changes to `copiedLabel` after
  copying.
- The confirmation is also sent to a polite `role="status"` live region, so screen-reader users
  hear "Copied!" without moving focus.
- Make the name specific when there are several copy buttons ("Copy API key"), or point to the
  value with `aria-describedby`.
- The check icon isn't the only confirmation: the text changes too.
- Copying needs a secure context (HTTPS or localhost). If the browser refuses, the button stays in
  its normal state.

## API Reference

| Prop          | Type                      | Default     |
| ------------- | ------------------------- | ----------- |
| `value`       | `string` (required)       | —           |
| `label`       | `string`                  | `"Copy"`    |
| `copiedLabel` | `string`                  | `"Copied!"` |
| `resetAfter`  | `number` (ms)             | `2000`      |
| `onCopy`      | `(value: string) => void` | —           |

Accepts every `Button` prop except `children`, including `variant`, `size` and `iconOnly`.
