## Usage

```tsx
import { Clipboard } from "@stefan-florescu/ui";
```

```tsx
<Clipboard value="npm install @stefan-florescu/ui" />
```

`Clipboard` is a client component. It copies `value` when pressed, shows its copied state for two
seconds (`resetAfter`) and announces it to screen readers. Place it next to, or inside, the
element that shows the value: a read-only `Input`, a code block or an address.

| Variant     | Tokens                                                                       | Use it for                              |
| ----------- | ---------------------------------------------------------------------------- | --------------------------------------- |
| `brand`     | `brand` · `brand-strong` on hover · `brand-foreground` label                 | A copy button next to a field.          |
| `secondary` | `neutral-secondary-medium` · `default-medium` border · `body`                | The end of an input group.              |
| `ghost`     | `body` icon · `neutral-quaternary` on hover · `fg-brand` copied icon         | An icon button inside a field or card.  |
| `tertiary`  | `neutral-primary-strong` · `default-strong` border · `fg-brand` copied state | A small labelled button in a code block |

## Accessibility

- A native `<button>`. Its name is `label` ("Copy" by default) and changes to `copiedLabel` after
  copying. Icon-only buttons use the label as their `aria-label`.
- The confirmation is also sent to a polite `role="status"` live region, so screen-reader users
  hear "Copied!" without moving focus. This replaces Flowbite's "Copy to clipboard" tooltip.
- Make the name specific when there are several copy buttons ("Copy API key").
- The copied state never relies on colour alone: the icon and the text change too.
- Keyboard focus draws a solid `ring` outline as well as Flowbite's halo.
- Fields are `readOnly` rather than Flowbite's `disabled readonly`, so they stay focusable and
  their value can be selected and read.
- In dark mode the `tertiary` button's label uses `heading` instead of Flowbite's `body`, and its
  copied state uses `heading` text with an `fg-brand-strong` icon instead of `fg-brand`: Flowbite's
  colours are under 4.5:1 on the `neutral-primary-strong` fill.
- Copying needs a secure context (HTTPS or localhost). If the browser refuses, the button stays in
  its normal state.

## API Reference

| Prop          | Type                                                 | Default     |
| ------------- | ---------------------------------------------------- | ----------- |
| `value`       | `string` (required)                                  | —           |
| `variant`     | `"brand" \| "secondary" \| "ghost" \| "tertiary"`    | `"brand"`   |
| `size`        | `"sm" \| "md"`                                       | `"md"`      |
| `iconOnly`    | `boolean`. Shows only the icon; `label` names it.    | `false`     |
| `label`       | `string`                                             | `"Copy"`    |
| `copiedLabel` | `string`                                             | `"Copied!"` |
| `resetAfter`  | `number` (ms)                                        | `2000`      |
| `onCopy`      | `(value: string) => void`                            | —           |
| `className`   | `string`. Merged with `cn()`; position it with this. | —           |

All other native `<button>` attributes are forwarded, including `ref` and `disabled`.
