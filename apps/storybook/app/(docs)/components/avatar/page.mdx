## Usage

```tsx
import { Avatar, AvatarGroup, AvatarGroupCounter } from "@stefan-florescu/ui";
```

```tsx
<Avatar src="/team/ana.jpg" alt="Ana Popescu" />
```

Avatars are circles by default. Set `shape="square"` for rounded squares.

### Dot indicator

Set `status` to `online`, `away`, `busy` or `offline`, and `statusPosition` to `top-right` or
`bottom-right`. Screen readers announce the status as text.

<ComponentPreview name="avatar-status" />

<Callout title="Don't rely on colour alone">

### Stacked

Wrap avatars in `AvatarGroup` and add `stacked` to each, so it is outlined against the next.
End the group with `AvatarGroupCounter` to show how many more there are.

### Avatar text

Pair the avatar with a name and details. When the name is visible, give the avatar an empty `alt`

Five sizes from `xs` (24px) to `xl` (144px). `md` (40px) is the default.

## Accessibility

- With `src`, the avatar renders an `<img>` with your `alt`. Initials and the placeholder are
  exposed as `role="img"` with the same name.
- Leave `alt` out (or empty) when the person's name is already shown next to the avatar; the
  avatar is then decorative and hidden from assistive technology.
- The status dot includes visually hidden text ("Online", "Busy"…), which you can change with
  `statusLabel`.
- `AvatarGroupCounter` becomes a link when you pass `href`. Give it an `aria-label` such as
  "99 more people".

## API Reference

### Avatar

| Prop             | Type                                        | Default          |
| ---------------- | ------------------------------------------- | ---------------- |
| `src`            | `string`                                    | —                |
| `alt`            | `string`                                    | —                |
| `initials`       | `string`                                    | —                |
| `size`           | `"xs" \| "sm" \| "md" \| "lg" \| "xl"`      | `"md"`           |
| `shape`          | `"circle" \| "square"`                      | `"circle"`       |
| `bordered`       | `boolean`                                   | `false`          |
| `stacked`        | `boolean`                                   | `false`          |
| `status`         | `"online" \| "away" \| "busy" \| "offline"` | —                |
| `statusPosition` | `"top-right" \| "bottom-right"`             | `"bottom-right"` |
| `statusLabel`    | `string`                                    | Status name      |

### AvatarGroup

Accepts all `<div>` attributes.

### AvatarGroupCounter

| Prop   | Type     | Default |
| ------ | -------- | ------- |
| `href` | `string` | —       |

All parts forward native attributes, including `ref` and `className`.
