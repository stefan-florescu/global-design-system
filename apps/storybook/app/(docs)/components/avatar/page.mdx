## Usage

```tsx
import { Avatar, AvatarGroup, AvatarGroupCounter } from "@stefan-florescu/ui";
```

```tsx
<Avatar src="/avatars/1.svg" alt="Jese Leos" />
```

## Examples

### Default avatar

Avatars are 40px circles by default. Set `shape="square"` for Flowbite's rounded square.

<ComponentPreview name="avatar-demo" />

### Bordered

Add `bordered` for a 2px `default` ring around the avatar, 4px from the image.

<ComponentPreview name="avatar-bordered" />

### Placeholder icon

Without `src` or `initials`, the avatar shows a person silhouette on `neutral-secondary-medium`.

<ComponentPreview name="avatar-placeholder" />

### Placeholder initials

Pass `initials` to show the person's initials on `neutral-tertiary` instead of an image.

<ComponentPreview name="avatar-initials" />

### Dot indicator

Set `status` to `online`, `away`, `busy` or `offline`, and `statusPosition` to `top-right` or
`bottom-right`. On squares the dot sits on the corner. Screen readers announce the status as text.

<ComponentPreview name="avatar-status" />

<Callout title="Don't rely on colour alone">
  The dot's colour is not enough for people who can't tell the colours apart. Where the status
  matters, also show it as visible text next to the avatar.
</Callout>

### Stacked

Wrap avatars in `AvatarGroup` and add `stacked` to each, so a 2px `buffer` border separates it
from the next. End the group with `AvatarGroupCounter` to show how many more there are.

<ComponentPreview name="avatar-stacked" />

### Avatar text

Pair the avatar with a name and details. When the name is visible, give the avatar an empty `alt`
so it isn't read twice.

<ComponentPreview name="avatar-text" />

## Accessibility

- With `src`, the avatar renders an `<img>` with your `alt`. Initials and the placeholder are
  exposed as `role="img"` with the same name.
- Leave `alt` out (or empty) when the person's name is already shown next to the avatar; the
  avatar is then decorative and hidden from assistive technology.
- Initials (`body` on `neutral-tertiary`) and the placeholder silhouette (`body-subtle` on
  `neutral-secondary-medium`) pass WCAG 2.2 AA in light and dark, as in Flowbite.
- The status dot includes visually hidden text ("Online", "Busy"…), which you can change with
  `statusLabel`.
- `AvatarGroupCounter` becomes a link when you pass `href`, with a solid focus outline. Give it an
  `aria-label` such as "99 more people". Its label uses `dark-foreground` instead of Flowbite's
  white.

## API Reference

### Avatar

| Prop             | Type                                                     | Default          |
| ---------------- | -------------------------------------------------------- | ---------------- |
| `src`            | `string`                                                 | —                |
| `alt`            | `string`                                                 | —                |
| `initials`       | `string`                                                 | —                |
| `size`           | `"2xs" \| "xs" \| "sm" \| "md" \| "lg" \| "xl" \| "2xl"` | `"md"`           |
| `shape`          | `"circle" \| "square"`                                   | `"circle"`       |
| `bordered`       | `boolean`                                                | `false`          |
| `stacked`        | `boolean`                                                | `false`          |
| `status`         | `"online" \| "away" \| "busy" \| "offline"`              | —                |
| `statusPosition` | `"top-right" \| "bottom-right"`                          | `"bottom-right"` |
| `statusLabel`    | `string`                                                 | Status name      |

### AvatarGroup

Accepts all `<div>` attributes.

### AvatarGroupCounter

| Prop   | Type                                 | Default |
| ------ | ------------------------------------ | ------- |
| `href` | `string`. Renders an `<a>` when set. | —       |

All parts forward native attributes, including `ref` and `className`.
