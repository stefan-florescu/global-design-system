## Usage

```tsx
import { Kbd } from "@stefan-florescu/ui";
```

```tsx
<p>
  Press <Kbd>Ctrl</Kbd> + <Kbd>K</Kbd> to search.
</p>
```

`Kbd` renders the semantic `<Kbd>` element, so keys use the monospace `font-mono` face, which suits
keyboard input best.

## Accessibility

- Renders the native `<Kbd>` element, which marks keyboard input. It has no ARIA role and is not
  interactive, so it needs no keyboard support or focus style.
- Screen readers read the key's text. Icon-only keys (arrow keys) need visually hidden text; the
  icon is decorative and hidden from assistive technology.
- Spell out keys the way people say them (`Ctrl`, `Shift`, `Esc`). Symbols such as `⌘` or `↑` may
  be read inconsistently, so pair them with text or a hidden name.
- When an element has a shortcut, also declare it with `aria-keyshortcuts` on that element; a
  `Kbd` hint is only visual.
- `heading` on `neutral-tertiary` passes WCAG 2.2 AA in both themes.

## API Reference

### Kbd

| Prop   | Type           | Default |
| ------ | -------------- | ------- |
| `size` | `"sm" \| "md"` | `"md"`  |

All native `<Kbd>` attributes are forwarded, including `ref` and `className`.

| Token              | Use                       |
| ------------------ | ------------------------- |
| `neutral-tertiary` | Key surface               |
| `default-medium`   | Key border                |
| `heading`          | Key label                 |
| `radius.base`      | Corners (12px; `sm`: 8px) |
| `font.mono`        | Key face (from `<Kbd>`)   |
