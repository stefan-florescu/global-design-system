## Usage

```tsx
import { Pagination } from "@stefan-florescu/ui";
```

```tsx
const [page, setPage] = useState(1);

<Pagination currentPage={page} totalPages={10} onPageChange={setPage} />;
```

`Pagination` is controlled: it shows `currentPage` and reports the page someone picks through
`onPageChange`. Pass `getPageHref` instead (or as well) to render links, which also works in Server
Components.

## Accessibility

- Renders a `<nav>` landmark named "Pagination" (change it with `aria-label`, for example "Search
  results", when a page has more than one) holding a list of controls.
- The current page has `aria-current="page"`. Page controls are named "Page 3" and so on (change
  it with `getPageLabel`); Flowbite announces only the number.
- Previous and next are real disabled states at the ends of the range: disabled `<button>`s, or,
  for links, an element with `role="link"` and `aria-disabled="true"` and no `href`, so it leaves
  the tab order. Flowbite never disables them.
- Icon-only previous and next keep their label as visually hidden text; the chevrons and arrows are
  hidden from assistive technology and flip in right-to-left layouts.
- The table summary ("Showing 11 to 20 of 100 Entries") and the single layout's "1 of 99" are
  polite live regions, so the new position is announced after previous or next is pressed.
- Every control draws the solid `ring` outline on keyboard focus and moves to the `z.raised` layer,
  so joined neighbours never cover it. Flowbite removes the outline (`focus:outline-none`).
- In "Single pagination" Flowbite's middle "1 of 99" is a button that does nothing; here it is
  text. Flowbite's tooltips on the icon buttons ("Single pagination", "Select input and buttons")
  are left out until a tooltip component exists; the buttons are named "Previous" and "Next".
- In "Select input and buttons" Flowbite shows the page count as the placeholder of a disabled
  field; here it is the field's value, named "Total pages".
- The ellipsis is hidden from assistive technology; the page names around it say where the range
  jumps.
- Disabled ends use Flowbite's disabled-button colours (`disabled`, `fg-disabled`), which are
  exempt from contrast minimums. Every other label passes WCAG 2.2 AA in both themes.

## API Reference

| Prop            | Type                                                  | Default           |
| --------------- | ----------------------------------------------------- | ----------------- |
| `currentPage`   | `number`                                              | —                 |
| `totalPages`    | `number`                                              | from `totalItems` |
| `onPageChange`  | `(page: number, event: MouseEvent) => void`           | —                 |
| `getPageHref`   | `(page: number) => string`                            | —                 |
| `layout`        | `"pagination" \| "navigation" \| "table" \| "single"` | `"pagination"`    |
| `size`          | `"sm" \| "md"`                                        | `"md"`            |
| `showIcons`     | `boolean`                                             | `false`           |
| `siblingCount`  | `number`                                              | `2`               |
| `showEllipsis`  | `boolean`                                             | `false`           |
| `previousLabel` | `string`                                              | `"Previous"`      |
| `nextLabel`     | `string`                                              | `"Next"`          |
| `getPageLabel`  | `(page: number) => string`                            | `` `Page ${n}` `` |
| `itemsPerPage`  | `number`                                              | `10`              |
| `totalItems`    | `number`                                              | —                 |
| `renderInfo`    | `(info: PaginationInfo) => ReactNode`                 | —                 |
| `aria-label`    | `string`                                              | `"Pagination"`    |
| `children`      | `ReactNode`                                           | —                 |

`renderInfo` replaces the table summary and the single layout's "1 of 99", for example to
translate them. It receives `currentPage`, `totalPages`, `firstItem`, `lastItem` and `totalItems`.
All other `<nav>` attributes are forwarded, including `ref` and `className`.
`getPaginationItems(currentPage, totalPages, siblingCount, showEllipsis)` returns the list of pages
(and ellipses) the component shows, for building your own layout.

| Token                      | Use                                   |
| -------------------------- | ------------------------------------- |
| `neutral-secondary-medium` | Control fill                          |
| `neutral-tertiary-medium`  | Hover fill and current page           |
| `default-medium`           | Borders                               |
| `body` / `heading`         | Labels, and labels on hover           |
| `fg-brand`                 | Current page                          |
| `disabled` / `fg-disabled` | Disabled previous and next            |
| `neutral-tertiary`         | Focus halo (single layout)            |
| `radius.base`              | Outer corners (12px)                  |
| `shadow.xs`                | Previous and next buttons, single bar |
