## Usage

```tsx
import { Calendar, DateRangePicker, Datepicker } from "@stefan-florescu/ui";
```

```tsx
<Datepicker label="Departure" name="departure" onChange={(date) => console.log(date)} />
```

`Datepicker`, `DateRangePicker` and `Calendar` are client components. `Datepicker` is a text
field with a calendar icon: type a date, or press the field to pick one from a `Calendar` in a
popover. Use `Calendar` on its own to show the calendar inline. No plugin or extra script is
needed.

## Options

### Autohide

Set `autoHide` to close the calendar right after selecting a date.

<ComponentPreview name="datepicker-autohide" />

### Action buttons

Set `showButtons` to add the "Today" and "Clear" buttons under the calendar: "Today" selects the
current day and "Clear" resets the selection.

<ComponentPreview name="datepicker-buttons" />

### Date format

Pass a `format` such as `mm-dd-yyyy` to change how the date is shown and typed. It understands
these tokens: `d`/`dd` day, `m`/`mm` month, `M`/`MM` month name, `D`/`DD` weekday name and
`yy`/`yyyy` year.

<ComponentPreview name="datepicker-format" />

### Max and min dates

Use `min` and `max` to set the earliest and latest dates that can be selected. Days outside them
are disabled, and the month buttons stop at the limits.

<ComponentPreview name="datepicker-min-max" />

### Orientation

Set `orientation` to `"bottom left"` (the default), `"bottom right"`, `"top left"` or
`"top right"` to choose where the calendar opens.

<ComponentPreview name="datepicker-orientation" />

### Title

Pass `title` to show a title above the calendar.

<ComponentPreview name="datepicker-title" />

### Week start

Set `weekStartsOn` (0 = Sunday, 1 = Monday…) and `locale` for month and weekday names.

<ComponentPreview name="datepicker-week-start" />

### Disabled days

Pass `isDateDisabled` to disable any day, for example weekends.

## Accessibility

- Follows the WAI-ARIA [date picker combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/examples/combobox-datepicker/)
  example. The field is a `combobox` with `aria-haspopup="dialog"` and `aria-expanded`, named by
  `label` ("Date" by default). The calendar is a non-modal `dialog` named "Choose date".
- The calendar is a `grid` named by the month ("October 2026"), which is announced when it
  changes. Each day is a button named with the full date, today has `aria-current="date"`, and
  selected days have `aria-selected`.
- Only one day is in the tab order, and it shows a solid `ring` outline when focused. Keyboard:

| Key                                       | Action                                                 |
| ----------------------------------------- | ------------------------------------------------------ |
| <Kbd>↓</Kbd> in the field                 | Opens the calendar and moves focus to the selected day |
| <Kbd>Enter</Kbd> in the field             | Reads the typed date                                   |
| <Kbd>←</Kbd> / <Kbd>→</Kbd>               | Previous / next day                                    |
| <Kbd>↑</Kbd> / <Kbd>↓</Kbd>               | Same day previous / next week                          |
| <Kbd>Home</Kbd> / <Kbd>End</Kbd>          | First / last day of the week                           |
| <Kbd>Page Up</Kbd> / <Kbd>Page Down</Kbd> | Previous / next month (with <Kbd>Shift</Kbd>: year)    |
| <Kbd>Enter</Kbd> / <Kbd>Space</Kbd>       | Selects the focused day                                |
| <Kbd>Esc</Kbd>                            | Closes the calendar and returns focus to the field     |

- Days of the previous and next month use `body-subtle` rather than `fg-disabled`, which is
  under 4.5:1, because those days can still be picked. Disabled days keep `fg-disabled`.
- Disabled days stay focusable so keyboard users can move past them, but they can't be selected.
- The field's border is the `input` token, like every form control.
- For dates far in the past, such as a birth date, separate day, month and year fields are faster
  and easier than a calendar.

## API Reference

### Datepicker

| Prop           | Type                                                           | Default         |
| -------------- | -------------------------------------------------------------- | --------------- |
| `value`        | `Date \| null`                                                 | —               |
| `defaultValue` | `Date \| null`                                                 | `null`          |
| `onChange`     | `(date: Date \| null) => void`                                 | —               |
| `label`        | `string`. Names the field and the calendar.                    | `"Date"`        |
| `placeholder`  | `string`                                                       | `"Select date"` |
| `name`         | `string`                                                       | —               |
| `id`           | `string`. The field's id, for a `<Label htmlFor>`.             | —               |
| `format`       | `string`                                                       | `"mm/dd/yyyy"`  |
| `autoHide`     | `boolean`                                                      | `false`         |
| `showButtons`  | `boolean`                                                      | `false`         |
| `todayLabel`   | `string`                                                       | `"Today"`       |
| `clearLabel`   | `string`                                                       | `"Clear"`       |
| `orientation`  | `"bottom left" \| "bottom right" \| "top left" \| "top right"` | `"bottom left"` |
| `disabled`     | `boolean`                                                      | `false`         |
| `className`    | `string`. Classes for the field's wrapper, such as a width.    | —               |

Also accepts the `Calendar` options `min`, `max`, `isDateDisabled`, `weekStartsOn`, `locale` and
`title`.

### DateRangePicker

Accepts the same options as `Datepicker`, with a range instead of a day:

| Prop                                  | Type                                       | Default                                     |
| ------------------------------------- | ------------------------------------------ | ------------------------------------------- |
| `value` / `defaultValue`              | `{ from: Date \| null; to: Date \| null }` | —                                           |
| `onChange`                            | `(range) => void`                          | —                                           |
| `startLabel` / `endLabel`             | `string`                                   | `"Start date"` / `"End date"`               |
| `startPlaceholder` / `endPlaceholder` | `string`                                   | `"Select date start"` / `"Select date end"` |
| `startName` / `endName`               | `string`                                   | —                                           |
| `separator`                           | `string`                                   | `"to"`                                      |

### Calendar

| Prop             | Type                                              | Default        |
| ---------------- | ------------------------------------------------- | -------------- |
| `mode`           | `"single" \| "range"`                             | `"single"`     |
| `value`          | `Date \| null` or `{ from, to }` for ranges       | —              |
| `defaultValue`   | Same as `value`                                   | —              |
| `onChange`       | `(date: Date) => void` or `(range) => void`       | —              |
| `rangeEdge`      | `"from" \| "to"`. Ranges: which end a click sets. | Alternates     |
| `min` / `max`    | `Date`                                            | —              |
| `isDateDisabled` | `(date: Date) => boolean`                         | —              |
| `weekStartsOn`   | `0 \| 1 \| 2 \| 3 \| 4 \| 5 \| 6`                 | `0`            |
| `locale`         | `string`                                          | Browser locale |
| `defaultMonth`   | `Date`                                            | Today          |
| `title`          | `ReactNode`                                       | —              |

### formatDate and parseDate

```tsx
formatDate(date: Date, format = "mm/dd/yyyy", locale?: string): string
parseDate(text: string, format = "mm/dd/yyyy", locale?: string): Date | null
```

The helpers the field uses to show and read dates, for your own date text.
