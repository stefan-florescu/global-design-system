## Usage

```tsx
import { BottomNavigation, BottomNavigationItem } from "@stefan-florescu/ui";
```

```tsx
<BottomNavigation>
  <BottomNavigationItem href="/" icon={<House aria-hidden />} active>
    Home
  </BottomNavigationItem>
  <BottomNavigationItem href="/settings" icon={<SlidersVertical aria-hidden />}>
    Settings
  </BottomNavigationItem>
</BottomNavigation>
```

The examples render inside a frame that stands in for the browser window. In your app, the bar is
fixed to the bottom of the viewport. Each item takes one equal column of a centred `max-w-lg`
grid.

<Callout title="Layering">
  `BottomNavigation` sits on the `z.fixed` layer (`z-fixed`), above sticky headers and below
  overlays, dialogs and toasts. See [Spacing & layout](/foundation/spacing-and-layout#layering).
</Callout>

### Online meeting control bar

Use this component to show a list of options for online video meetings by showing a list of
options such as muting the microphone, hiding the camera, adjusting the volume and more.

These bars hold controls rather than destinations, so they are not a `<nav>`: the bar is a
`<section>` named "Meeting controls" (a region landmark) styled with `bottomNavigationVariants()`,
and the buttons are [`Button`](/components/button)s in labelled groups. "Mute microphone" and
"Hide camera" are toggle buttons (`aria-pressed`) whose icons change while they are on; "Show
options" opens a [`Dropdown`](/components/dropdown) menu, and "Adjust volume" opens a panel with a
volume [`Range`](/forms/range). The clock and the side groups show once the bar is at least 672px
wide: the bar is a query container (`@container`, `@2xl:`), so its layout follows its own width
rather than the viewport's, and the centre column sizes to its buttons so they always fit.

<ComponentPreview name="bottom-navigation-meeting" flush />

### Video player bar

Use this component to show control buttons for a video or audio that is playing in the browser to
control the volume, navigate between videos, pause or start the video, and more.

The play/pause button changes its name, tooltip and icon to the action it takes ("Pause video",
"Play video"), "Captions" is a toggle button, and the playback position is a
[`Progress`](/components/progress) bar named "Playback position" that announces "3:45 of 5:00".
The three columns share the bar equally, as in Flowbite.

## Accessibility

- Renders a `<nav>` landmark named "Bottom navigation" (change it with `aria-label`) containing a
  list, so screen readers announce how many destinations there are.
- The current page has `aria-current="page"`, which screen readers announce, and is coloured
  `fg-brand` (Flowbite only colours items on hover). If colour is the only cue in your design, add
  another one, such as a filled icon.
- `hideLabel` keeps the label as visually hidden text; every item always has a name. Flowbite's
  tooltips on icon-only items are [`Tooltip`](/components/tooltips)s in label mode: they show the
  same name on hover and keyboard focus and are read once. <Kbd>Escape</Kbd> hides them. The
  app bar's add button is named by its tooltip, "Create new item".
- Keyboard focus draws a solid `ring` outline inside the item; Flowbite has no focus style.
- Each item fills its share of the 64px-high bar, well above the 24×24px minimum target size.
- A fixed bar covers the bottom of the page. Add matching padding to your layout so no content is
  hidden behind it.

In the online meeting control bar and the video player bar:

- The bars are `<section>` region landmarks ("Meeting controls", "Video player"), not `<nav>`,
  because they hold controls rather than links to pages. Each cluster of buttons is a
  `role="group"` with a name ("Call controls", "Playback controls"…), and <Kbd>Tab</Kbd> moves
  through the buttons one by one. They are not `role="toolbar"`s: a toolbar promises a single tab
  stop with arrow-key movement, which these examples do not implement.
- Every icon-only button is named by its [`Tooltip`](/components/tooltips) in label mode, which
  shows on hover and keyboard focus. Flowbite's "Show options" button and its "Adjust volume"
  buttons have no tooltip; ours do, and step aside while their menu or panel is open. Where
  Flowbite's hidden name and tooltip differ, the tooltip's text is the name: "Full screen" (not
  "Expand") and "Captions" (not "Toggle captions", which would repeat the toggle state).
- Mute, camera and captions are toggle buttons: their name stays the same and `aria-pressed` says
  whether they are on, as the WAI-ARIA button pattern recommends. Pressed buttons also change their
  icon (microphone off, camera off) or turn `fg-brand`, so the state is not shown by colour alone.
  Play/pause instead swaps its name and icon between "Pause video" and "Play video", the usual
  pattern for media controls. Flowbite's buttons do not change.
- "Show options" opens a menu (arrow keys, <Kbd>Escape</Kbd> returns focus). "Adjust volume" opens
  a dialog panel with a labelled slider that announces the volume as a percentage; Flowbite's
  button does nothing.
- The video's playback position is a `progressbar` named "Playback position" with the value text
  "3:45 of 5:00"; the times beside it are hidden from screen readers so they are not read twice.
  In a real player that lets people seek, use a [`Range`](/forms/range) slider instead.
- The video thumbnail is decorative (`alt=""`): the title next to it names the video. Buttons keep
  Flowbite's soft focus halo and add the solid `ring` outline on keyboard focus.

## API Reference

### BottomNavigation

| Prop         | Type                              | Default               |
| ------------ | --------------------------------- | --------------------- |
| `position`   | `"fixed" \| "sticky" \| "static"` | `"fixed"`             |
| `floating`   | `boolean`                         | `false`               |
| `bordered`   | `boolean`                         | `false`               |
| `header`     | `ReactNode`                       | —                     |
| `aria-label` | `string`                          | `"Bottom navigation"` |

### BottomNavigationItem

| Prop        | Type        | Default |
| ----------- | ----------- | ------- |
| `href`      | `string`    | —       |
| `icon`      | `ReactNode` | —       |
| `active`    | `boolean`   | `false` |
| `hideLabel` | `boolean`   | `false` |

Items render an `<a>` with `href`, otherwise a `<button>`, and forward the matching native
attributes. Icons are drawn at 24px.

| Token                      | Use                    |
| -------------------------- | ---------------------- |
| `neutral-primary-soft`     | Bar surface            |
| `default`                  | Top border, dividers   |
| `body`                     | Icons and labels       |
| `neutral-secondary-medium` | Item hover surface     |
| `fg-brand`                 | Hover and current item |
| `z.fixed`                  | Layer of the fixed bar |
