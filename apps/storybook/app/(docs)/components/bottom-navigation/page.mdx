## Usage

```tsx
import { BottomNavigation, BottomNavigationItem } from "@stefan-florescu/ui";
```

```tsx
<BottomNavigation>
  <BottomNavigationItem href="/" icon={<House aria-hidden />} active>
    Home
  </BottomNavigationItem>
  <BottomNavigationItem href="/settings" icon={<Settings aria-hidden />}>
    Settings
  </BottomNavigationItem>
</BottomNavigation>
```

The examples render inside a frame that stands in for a phone screen. In your app, the bar is
fixed to the bottom of the viewport.

<Callout title="Layering" variant="warning">
  The design system has no z-index tokens yet, so `BottomNavigation` sets none. If it must sit above
  other positioned content, add a z-index from your app's layer scale with `className`.
</Callout>

## Accessibility

- Renders a `<nav>` landmark named "Bottom navigation" (change it with `aria-label`) containing a
  list, so screen readers announce how many destinations there are.
- The current page has `aria-current="page"`, which screen readers announce. Visually it is shown
  by the brand text colour; if that is the only cue in your design, add another one, such as a
  filled icon.
- `hideLabel` keeps the label as visually hidden text; every item always has a name.
- Each item fills its share of the 64px-high bar, well above the 24×24px minimum target size.
- A fixed bar covers the bottom of the page. Add matching padding to your layout so no content is
  hidden behind it.

## API Reference

### BottomNavigation

| Prop         | Type                  | Default               |
| ------------ | --------------------- | --------------------- |
| `position`   | `"fixed" \| "static"` | `"fixed"`             |
| `floating`   | `boolean`             | `false`               |
| `bordered`   | `boolean`             | `false`               |
| `aria-label` | `string`              | `"Bottom navigation"` |

### BottomNavigationItem

| Prop        | Type        | Default |
| ----------- | ----------- | ------- |
| `href`      | `string`    | —       |
| `icon`      | `ReactNode` | —       |
| `active`    | `boolean`   | `false` |
| `hideLabel` | `boolean`   | `false` |

Items render an `<a>` with `href`, otherwise a `<button>`, and forward the matching native
attributes.
