## October 2026 — Color foundation

- 22 primitive colour palettes (11 steps each, OKLCH) and 34 semantic colour tokens for text,
  backgrounds and borders.
- Light and dark themes; every checked colour pairing is verified against WCAG 2.2 AA on each build.
- Tailwind utilities for semantic colours: `text-heading`, `bg-brand`, `border-default`, `ring-focus`…
- The Color page documents the palettes, tokens per theme, usage, theming and accessibility.

## October 2026 — Documentation site

- New documentation site with header search, light/dark theme and on-page anchors.
- Component page template, demonstrated with the Button page.
- Foundation pages for Color, Typography, Spacing & Layout and Border & Radius (content in progress).

## October 2026 — Foundation scaffold

- Monorepo with tokens, themes, UI and icons packages.
- CI, release pipeline and Vercel deployment.
