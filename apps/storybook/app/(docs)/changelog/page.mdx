## October 2026 — Alert, Avatar, Badge, Banner, Bottom Navigation, Breadcrumb

- Six new components in `@stefan-florescu/ui`, modelled on Flowbite and built on the semantic
  tokens: `Alert`, `Avatar`, `Badge`, `Banner`, `BottomNavigation` and `Breadcrumb`.
- Each has a docs page with live examples, accessibility notes and an API reference.
- New icons: Clock, House, Megaphone, Settings, User and Wallet.

## October 2026 — Accordion

- New `Accordion` component in `@stefan-florescu/ui`: single or multiple open items, a brand colour
  option, flush style, icons and nesting, with full keyboard support.
- The Accordion page shows every example with live code.

## October 2026 — Button

- New `Button` component in `@stefan-florescu/ui`: brand, primary, secondary, outline, ghost,
  success, warning, destructive, info and link variants, an `outline` style, five sizes, pills,
  icon-only, loading, disabled and full-width buttons.
- `buttonVariants()` styles links and other elements as buttons.
- The Button page shows every example with live code.

## October 2026 — Foundations

- New foundation tokens: 8 colour scales (80 primitives), 48 semantic colour tokens for light and
  dark, a 4px spacing scale, typography (Inter, 13 sizes, 6 weights), border widths, a radius
  scale, elevation and icon sizes.
- Colour contrast is verified against WCAG 2.2 AA in both themes on every build.
- Tailwind utilities map to the semantic tokens (`bg-background`, `text-muted-foreground`,
  `border-border`, `ring-ring`…).
- New site design with Color, Typography, Spacing & layout and Border & radius pages.
- Icons render from lucide with a 1.5 stroke.

## October 2026 — Documentation site

- New documentation site with header search, light/dark theme and on-page anchors.
- Component page template, demonstrated with the Button page.
- Foundation pages for Color, Typography, Spacing & Layout and Border & Radius (content in progress).

## October 2026 — Foundation scaffold

- Monorepo with tokens, themes, UI and icons packages.
- CI, release pipeline and Vercel deployment.
