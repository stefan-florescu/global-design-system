## October 2026 — Color page and field borders

- The Color page shows each scale on two rows of six, with larger swatches and the hex code of
  every shade; clicking a swatch copies the hex.
- Field, checkbox, radio and toggle borders now use Flowbite's gray-200 (gray-700 in dark), and the
  File Input's "Choose file" button sits inside the field with rounded start corners.

## October 2026 — Flowbite v4 look

- Every component now looks like the matching one on flowbite.com (Flowbite v4), class for class.
  Each docs page mirrors Flowbite's examples, in Flowbite's order.
- New foundation: Tailwind v4's palette in OKLCH and Flowbite v4's semantic colour roles
  (`bg-brand`, `hover:bg-brand-strong`, `text-heading`, `text-body`, `border-default`…), Flowbite's
  radius scale (`rounded-base` 12px) and shadows.
- Where Flowbite misses WCAG 2.2 AA, we use the nearest passing value, and each page lists these
  differences. Examples: darker field borders (`input`), a solid keyboard-focus outline (`ring`),
  dark text on warning fills.
- Breaking API changes, such as Button `danger` replacing `destructive`, are listed in the release
  notes.

## October 2026 — Forms

- New **Forms** section with twelve components: Input Field, File Input, Search Input, Number
  Input, Phone Input, Select, Textarea, Timepicker, Checkbox, Radio, Toggle and Range.
- Shared `Label`, `HelperText` and `Fieldset` for accessible labels, hints, errors and groups.
- Every field uses the `input` border token (3:1 against the page) with invalid, valid and
  disabled states, and native controls for keyboard and screen-reader support.
- Clipboard examples now use read-only inputs; new newsletter banner and sign-in card examples.

## October 2026 — Button Group, Card, Carousel, Chat Bubble, Clipboard, Datepicker

- Six new components in `@stefan-florescu/ui`, modelled on Flowbite: `ButtonGroup`, `Card`,
  `Carousel`, `ChatBubble`, `Clipboard`, and `Datepicker` with an inline `Calendar` that also
  picks date ranges.
- Carousel and Datepicker follow the WAI-ARIA carousel and date picker patterns, with full keyboard
  support and reduced-motion handling.
- New icons: Calendar, Download, Pause, Play and Star.

## October 2026 — Alert, Avatar, Badge, Banner, Bottom Navigation, Breadcrumb

- Six new components in `@stefan-florescu/ui`, modelled on Flowbite and built on the semantic
  tokens: `Alert`, `Avatar`, `Badge`, `Banner`, `BottomNavigation` and `Breadcrumb`.
- Each has a docs page with live examples, accessibility notes and an API reference.
- New icons: Clock, House, Megaphone, Settings, User and Wallet.
- New layer tokens (`--sds-z-*`, `z-*` utilities) give fixed bars, overlays, dialogs and toasts one
  stacking order. Banner and Bottom Navigation use the `fixed` layer.

## October 2026 — Accordion

- New `Accordion` component in `@stefan-florescu/ui`: single or multiple open items, a brand colour
  option, flush style, icons and nesting, with full keyboard support.
- The Accordion page shows every example with live code.

## October 2026 — Button

- New `Button` component in `@stefan-florescu/ui`: brand, primary, secondary, outline, ghost,
  success, warning, destructive, info and link variants, an `outline` style, five sizes, pills,
  icon-only, loading, disabled and full-width buttons.
- `buttonVariants()` styles links and other elements as buttons.
- The Button page shows every example with live code.

## October 2026 — Foundations

- New foundation tokens: 8 colour scales (80 primitives), 48 semantic colour tokens for light and
  dark, a 4px spacing scale, typography (Inter, 13 sizes, 6 weights), border widths, a radius
  scale, elevation and icon sizes.
- Colour contrast is verified against WCAG 2.2 AA in both themes on every build.
- Tailwind utilities map to the semantic tokens (`bg-background`, `text-muted-foreground`,
  `border-border`, `ring-ring`…).
- New site design with Color, Typography, Spacing & layout and Border & radius pages.
- Icons render from lucide with a 1.5 stroke.

## October 2026 — Documentation site

- New documentation site with header search, light/dark theme and on-page anchors.
- Component page template, demonstrated with the Button page.
- Foundation pages for Color, Typography, Spacing & Layout and Border & Radius (content in progress).

## October 2026 — Foundation scaffold

- Monorepo with tokens, themes, UI and icons packages.
- CI, release pipeline and Vercel deployment.
